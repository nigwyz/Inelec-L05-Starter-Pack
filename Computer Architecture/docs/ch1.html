1Digital systems

An analog signal can take any value in a continuous range: a microphone voltage, a temperature, a light level. A digital (logic) signal is restricted to a small set of discrete values—in binary logic, just two: 0 and 1, also written L (low) and H (high).

The real world is analog, so a system that talks to it needs converters: an ADC (analog-to-digital converter) on the way in, and a DAC (digital-to-analog converter) on the way out.

Why digital wins

  • Easy to design with Boolean algebra
  • High performance and small size
  • Robust to noise: a small disturbance does not change a 0 into a 1
  • Low cost through integration
  • Easy to store, copy, and process

Design styles

  • Software: a program runs on a processor (µP, µC, DSP, GPU)
  • Hardware: a circuit is built as PCB, ASIC, or programmable logic (PLD/CPLD/FPGA)
  • Hardware/software: both, partitioned by the designer

Bits, bytes, and bit-vectors

A bit is one binary digit. A group of bits is a bit-vector. In a bit-vector, the MSB (most significant bit) is the leftmost bit and the LSB (least significant bit) is the rightmost. Eight bits form a byte.

2Logic values vs. physical values

A logic 1 is not one exact voltage—it is a range. The datasheet guarantees:

  • VOH: minimum output voltage that still counts as High.
  • VOL: maximum output voltage that still counts as Low.
  • VIH: minimum input voltage guaranteed to be read as High.
  • VIL: maximum input voltage guaranteed to be read as Low.

This creates a forbidden band between VIL and VIH. A receiver is not required to interpret a voltage there, which is exactly what gives digital circuits their noise immunity.

Noise margins measure how much disturbance the link can survive:

NM_H = V_OH(min) − V_IH(min)
NM_L = V_IL(max) − V_OL(max)

For the slide’s 5 V HCMOS example: VOL = 0.26 V, VOH = 4.48 V, VIL = 1 V, VIH = 3.5 V.

NM_L = 1.00 − 0.26 = 0.74 V
NM_H = 4.48 − 3.50 = 0.98 V

The slide prints 0.96 V for NMH; the arithmetic gives 0.98 V. Use the formula and your own subtraction—this is exactly the kind of discrepancy you should re-derive instead of memorizing.

3Binary representation

Positional notation

In a positional system each digit is multiplied by a power of the base. Decimal 57 means 5×10 + 7. Binary works the same way with base 2:

N = a_k a_(k−1) … a_1 a_0  (base 2)
N = Σ a_i × 2^i        with a_i ∈ {0, 1}

So 1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13.

Decimal → binary by repeated division

Divide by 2 repeatedly and read the remainders from the last one to the first. For 53:

53 ÷ 2 = 26  remainder 1   ← LSB
26 ÷ 2 = 13  remainder 0
13 ÷ 2 =  6  remainder 1
 6 ÷ 2 =  3  remainder 0
 3 ÷ 2 =  1  remainder 1
 1 ÷ 2 =  0  remainder 1   ← MSB

53₁₀ = 110101₂

Hexadecimal is shorthand for bits

Group bits in fours and convert each nibble to one hex digit. This is why a byte is always exactly two hex digits.

1011 1100₂ = B C₁₆ = BCH
1111 1111₂ = F F₁₆ = FFH

Binary arithmetic

Addition follows the same column rules as decimal, with a carry when a column reaches 2. Multiplication is repeated shifted addition.

4Signed numbers and two’s complement

Four common signed representations exist. With 4 bits, the value +5 and −5 become:

Representation+5−5Idea
Sign-magnitude01011101MSB is the sign, rest is magnitude
1’s complement01011010Invert all bits
2’s complement01011011Invert all bits, then add 1
Excess-2n−1−111000010Add a bias (for n = 4, bias = 7)

Why two’s complement wins: it lets the same adder perform signed and unsigned addition. The proof is short and worth remembering:

Z + Z̄ = 111…1
Z + Z̄ + 1 = 000…0   (ignoring the MSB carry)
therefore  −Z = Z̄ + 1

Addition proceeds as ordinary binary addition; the MSB carry is discarded.

Range

For an n-bit two’s-complement number the range is −2n−1 to +2n−1 − 1. For 8 bits: −128 to +127. Unsigned 8-bit is 0 to 255.

Two’s-complement in one page

  1. Write the positive value in binary using the full width.
  2. Invert every bit.
  3. Add 1.

To read a negative pattern back: the leading bit is 1, so the value is negative. Invert, add 1, and put a minus sign in front.

−5 in 8 bits:
   0000 0101   (+5)
   1111 1010   (invert)
   1111 1011   (+1)  = FBH

FBH back to decimal:
   1111 1011
   0000 0100   (invert)
   0000 0101   (+1) → 5 → so −5

Signed overflow

Overflow can occur only when adding two numbers of the same sign. The result then has the wrong sign. Equivalently, overflow is detected when the carry into the MSB differs from the carry out of the MSB.

Carry ≠ overflow. Carry is about unsigned range; overflow is about signed range. A single addition can set carry without overflow, overflow without carry, both, or neither. The flags lab above shows all four flags at once—use it until the distinction is automatic.

5Combinational logic circuits

A combinational circuit’s output depends only on its present inputs—it has no memory. A sequential circuit’s output depends on present inputs and past inputs (its state). That single distinction separates an adder from a register.

Any combinational circuit can be described in several equivalent ways: a Boolean equation (sum of products, product of sums), a truth table, a logic diagram, a binary decision diagram, or a timing diagram. Being able to move between representations is the actual skill.

Basic gates

NAND and NOR are called universal because either one alone can implement every other gate. In CMOS, NAND and NOR are also the natural gates to build, which is why AND and OR are usually made as NAND/NOR followed by an inverter.

Propagation delay and glitches

Real gates do not switch instantly. tpHL is the high-to-low delay, tpLH the low-to-high delay, and tr/tf the rise/fall times. Delays matter because paths with different delays can produce a short wrong output—a glitch. The classic example is S = A·A̅: logically always 0, but the two paths to the AND gate have different delays, so a narrow pulse can appear.

This is also why timing is a real design constraint, not a formality: the circuit must be stable before the next clock edge.

Karnaugh maps

A Karnaugh map is a truth table rearranged so that adjacent cells differ in exactly one variable. Grouping 1s in powers of two (1, 2, 4, 8) yields a minimal sum-of-products expression. It is the fastest hand method for small functions and appears in the design of adders, decoders, and control logic.

6MUX, decoder, tri-state, adders, ALU

Multiplexer (MUX)

A MUX selects one of several inputs and routes it to a single output. A 4-to-1 MUX needs two select lines. The 74LS153 is a dual 4-input MUX.

Y = S1̅·S0̅·I0 + S1̅·S0·I1 + S1·S0̅·I2 + S1·S0·I3

In a CPU, MUXes choose which register drives the internal bus and which ALU result is written back.

Interactive · 4-to-1 multiplexerchoose select lines

Decoder and encoder

A decoder takes an n-bit input and asserts exactly one of 2n outputs. The 74LS138 is a 3-to-8 decoder with active-low outputs and enable inputs. An encoder does the reverse: it reports which input is active as a binary code.

Decoders are how a CPU selects one memory chip or one register: the address bits are decoded into a single select line.

Tri-state buffer

A tri-state buffer has three output states: 0, 1, and Z (high impedance, effectively disconnected). It is the component that makes a shared bus possible—many devices connect to the same wire, but only the enabled one drives it.

Half adder, full adder, ripple-carry adder

A half adder adds two bits and produces sum and carry:

S = A ⊕ B
C = A · B

A full adder adds three bits (A, B, and carry-in):

S   = A ⊕ B ⊕ Cin
Cout = A·B + Cin·(A ⊕ B)

Chain n full adders and you get an n-bit ripple-carry adder: each carry ripples into the next stage. That is simple but slow, because the last sum must wait for the carry to travel through every stage.

To build a subtractor, invert B and set the first carry-in to 1. That is exactly “add the two’s complement”:

A − B = A + B̅ + 1

One control signal can therefore select addition or subtraction with the same adder hardware.

Interactive · Full addertoggle A, B, Cin

The ALU

The Arithmetic and Logic Unit is the collection of adders, logic gates, and a MUX that selects which operation result leaves the unit. Control signals choose the operation; flags (zero, sign, carry, overflow) summarize the result for later conditional branches.

Mental model. Data path = registers + ALU + buses. Control = the signals that tell the data path what to do. Chapter 3 makes this concrete; Chapter 4 will show how those signals are generated.

7Sequential circuits

A sequential circuit remembers. The basic storage element is built from cross-coupled gates, and its behavior is defined by a clock.

Latch

A transparent D latch follows the input while the enable/clock is high, and holds the last value when it goes low. The 74LS373 is an octal transparent latch with tri-state outputs.

Book corner — the SR latch (Stallings §11.4). The simplest memory element is two NOR gates cross-coupled: each output feeds the other gate’s input. Set S=1 and the Q output goes to 1 and stays there even after S returns to 0; set R=1 and Q resets to 0 and stays there. The cross-coupling is the memory. Its forbidden input is S=R=1, which drives both outputs to 0 and makes the next state unpredictable. A D latch fixes that by deriving S and R from one data input and an enable, so the two can never both be active.

D flip-flop

A positive-edge-triggered D flip-flop captures D only at the rising clock edge. Between edges it holds its value. The 74LS74 contains two such flip-flops with preset and clear.

Q⁺ = D   (at the active clock edge)

Three timing numbers define reliable operation:

  • Setup time tSU: D must be stable this long before the edge.
  • Hold time tH: D must remain stable this long after the edge.
  • Propagation delay tPD: how long after the edge the output becomes valid.

Registers, shift registers, counters

An n-bit register is simply n D flip-flops sharing a clock: Qi(t⁺) = Di(t). A shift register connects each flip-flop to the next, so bits move one position per clock. A counter adds feedback so the state advances through a fixed sequence.

Shift register:
Q0(t+1) = Q1(t)
Q1(t+1) = Q2(t)
Q2(t+1) = Q3(t)
Q3(t+1) = D(t)

For the 3-bit counter in the slides:

Q0(t+1) = Q0(t)
Q1(t+1) = Q0(t) ⊕ Q1(t)
Q2(t+1) = Q0(t)·Q1(t) ⊕ Q2(t)

8Logic families and CMOS

TTL (Transistor–Transistor Logic) is built from bipolar transistors and was dominant until CMOS replaced it in the 1990s. CMOS (Complementary MOS) uses paired NMOS and PMOS transistors and is the basis of almost all modern digital ICs.

How the transistors switch

TransistorConditionState
NMOSVGS = 0OFF
NMOSVGS = VDDON
PMOSVSG = 0OFF
PMOSVSG = VDDON

A PMOS turns on when its gate is pulled low; an NMOS turns on when its gate is pulled high.

CMOS inverter

One PMOS and one NMOS, gates tied together as the input:

  • Input = 0 → NMOS OFF, PMOS ON → output pulled to VDD (1).
  • Input = 1 → PMOS OFF, NMOS ON → output pulled to ground (0).

Because one transistor is always off, the steady-state path from VDD to ground is broken. That is the key to CMOS’s low power consumption.

Interactive · CMOS inverter and NANDtoggle inputs

CMOS NAND and NOR

NMOS transistors in series implement AND (both must conduct); NMOS in parallel implement OR (either can conduct). The PMOS network is the dual: series NMOS ↔ parallel PMOS, and vice versa.

  • NAND: two NMOS in series to ground, two PMOS in parallel to VDD.
  • NOR: two NMOS in parallel to ground, two PMOS in series to VDD.
  • AND / OR: a NAND/NOR followed by an inverter (more transistors, but the same idea).

Complex CMOS gates

For a static CMOS gate, the pull-down network (PDN) connects the output to ground when the output should be 0, so it realizes Y̅ using NMOS transistors: AND → series, OR → parallel. The pull-up network (PUN) is the exact dual using PMOS transistors.

Example:  Y = (A·B + C)̅
PDN:      A series B, in parallel with C
PUN:      A parallel B, in series with C

For the exam function Y = AB + AC + AD, first factor it:

Y = A(B + C + D)

The usual course drawing is:

PDN:  A in series with (B ∥ C ∥ D)
PUN:  A in parallel with (B series C series D)

Strictly, a static CMOS PDN realizes Y̅; the drawing above places the PDN in the position that conducts when the bracketed expression is true. If your solution expects the literal function Y, add an inverter after the gate (or state the convention used in the course). For the exam, the marks come from getting the series/parallel topology and its dual right.

Check yourself
Using 8-bit two’s complement, what is the decimal value of 1110 0010₂?
Show reasoning
The MSB is 1, so the value is negative. Invert: 0001 1101, add 1: 0001 1110₂ = 30. Therefore the value is −30. The unsigned reading is 226—same bits, different interpretation.
Check yourself
An 8-bit addition of two positive two’s-complement numbers produces 1000 0001. What happened?
Show reasoning
Adding two positive 8-bit numbers should give a result in 0…127. 1000 0001 is 129 unsigned, but as two’s complement it is negative (−127). The result sign contradicts the operands, so signed overflow occurred.
Check yourself
Why is a tri-state buffer essential on a shared bus?
Show reasoning
With many outputs tied to one wire, two active drivers would fight each other. The Z state removes the inactive devices electrically, leaving exactly one driver.
