Chapter 3

Discrete-Time Fourier Series

The Fourier series for discrete-time signals: the synthesis equation that builds a signal from its spectrum, the analysis equation that reads the spectrum back, and the identities that let you manipulate coefficients without recomputing them.

1Why a Fourier series for discrete time?

A periodic discrete-time sequence with period N can be expanded exactly as a finite sum of complex exponentials — there are only N independent harmonics, not infinitely many. This is the discrete-time Fourier series (DFS), and it is the discrete-time twin of the continuous Fourier series.

Synthesis  x[n] = Σk=0N−1 ak ej2πkn/N ,   n = 0,1,…,N−1   ·   Analysis  ak = (1/N) Σn=0N−1 x[n] e−j2πkn/N
Which is which. Synthesis goes from coefficients to the signal (you are given aₖ and asked for x[n]). Analysis goes from the signal to the coefficients (you are given x[n] and asked for aₖ). Both appear in the controls — 2023 Ex 3.1 is synthesis, make-up Ex 2 is analysis.
The index convention. Some books write the sum from k = −N/2 to N/2−1. The professor's paper uses k = 0 … N−1. If the question gives coefficients for negative k (as 2023 Ex 3 does: −1 ≤ k ≤ 1), wrap them around: a_{−1} is a_{N−1} and a_{−2} is a_{N−2}.

2Synthesis and analysis in practice

Synthesis is a plain matrix multiplication: build the N × N DFT matrix with entries W_N^{kn} (W_N = e^{−j2π/N}) and multiply. Analysis uses the conjugate matrix with the 1/N factor.

[x] = F [a]   with   Fkn = WNkn,   [a] = (1/N) F* [x]
DFS synthesizeredit the coefficients, watch the periodic signal and Parseval

3Two control questions, worked

Worked solution · 2023 control Exercise 3.1 (5 marks)

Question. Consider the periodic signal x[n] with period N = 5, if

ak = { jk    −1 ≤ k ≤ 1
         −1      k = ±2 }

Step 1 — move the coefficients into the 0 … N−1 range. With N = 5: a₀ = j⁰ = 1, a₁ = j, a₂ = −1, a₃ = a₋₂ = −1, a₄ = a₋₁ = j⁻¹ = −j.

Step 2 — x[0]. At n = 0 every exponential equals 1, so x[0] = Σₖ aₖ = 1 + j − 1 − 1 − j = −1.

Step 3 — the closed form. Write the synthesis sum and pair the conjugate terms:

x[n] = Σk=−22 ak ej2πkn/5
= 1 + j ej2πn/5 − ej4πn/5 − ej6πn/5 − j ej8πn/5
= 1 + j(ejθ − e−jθ) − (ej2θ + e−j2θ)   (θ = 2πn/5)
= 1 − 2 sin(2πn/5) − 2 cos(4πn/5)

using j(e^{jθ} − e^{−jθ}) = j·2j sinθ = −2 sinθ.

Step 4 — sanity check. The result is real (the coefficients came in conjugate pairs), it is periodic with period 5, and x[0] = 1 − 0 − 2 = −1 ✓. The five values over one period are −1, 0.7159, −0.7936, 1.5575, 4.5201.

Why the answer is real. a_{−k} = aₖ* here: a₁ = j and a₄ = −j = a₁*; a₂ = a₃ = −1 (both real). A conjugate-symmetric spectrum always produces a real signal.
Worked solution · 2024–25 control Exercise 3.1 (5 marks)

Question. Period N = 7, with a₀ = 0, a±₁ = 1, a±₂ = 2, a±₃ = 1, and 0 outside |k| ≤ 3. Synthesise x[n].

Step 1 — the sum. Because the coefficients are real and symmetric, pair k with −k:

x[n] = Σk=−33 ak ej2πkn/7
= a₀ + Σk=13 ak( ej2πkn/7 + e−j2πkn/7 )
= 0 + 2a₁ cos(2πn/7) + 2a₂ cos(4πn/7) + 2a₃ cos(6πn/7)

Step 2 — substitute.

x[n] = 2 cos(2πn/7) + 4 cos(4πn/7) + 2 cos(6πn/7)

Step 3 — check. x[0] = 2 + 4 + 2 = 8, and Σₖ aₖ = 0 + 2(1 + 2 + 1) = 8 ✓. The seven values are 8, −1.445, −2.802, 0.247, 0.247, −2.802, −1.445.

The general shortcut. If a₋ₖ = aₖ (real and even spectrum), then x[n] = a₀ + 2Σk=1 aₖ cos(2πkn/N) — write it as a sum of cosines and you are done. Half the marks come from this pairing step alone.

4Parseval

Σn=0N−1 |x[n]|² = N · Σk=0N−1 |ak|²

Parseval says the energy of the periodic signal equals N times the energy of its coefficient sequence. It is the discrete-time version of the continuous Parseval relation, and it is the fastest way to answer “compute the finite summation”.

Worked with the 2023 coefficients. a = [1, j, −1, −1, −j], so Σ|aₖ|² = 1 + 1 + 1 + 1 + 1 = 5 and Σₙ₌₀⁴|x[n]|² = 5 × 5 = 25. For 2024–25: Σ|aₖ|² = 2(1 + 4 + 1) = 12 and Σₙ₌₀⁶|x[n]|² = 7 × 12 = 84. Both are sums over one period only — do not multiply by another N.
The factor N is where the marks go. Write it as Σ|x[n]|² = N Σ|aₖ|² and say it out loud. Dropping the N, or summing over more than one period, is the single most common error in this part of the paper.

2023 True/False 4 — the one everybody gets wrong. “A real discrete-time periodic signal has real Fourier series coefficients.” False. Take x[n] = cos(2πn/N): it is real, but its coefficients are a₁ = a_{N−1} = ½ and the rest zero — that one happens to be real. Take x[n] = cos(2πn/N + π/4) instead: a₁ = ½e^{−jπ/4}, which is complex, even though x[n] is perfectly real. Real signal ⇒ conjugate symmetry, not real coefficients.
How many coefficients are forced to be real? Conjugate symmetry says a_{N−k} = aₖ*. A coefficient is its own conjugate only if it is real, and that happens when k ≡ N−k (mod N), i.e. k = 0 and, when N is even, k = N/2. So: N odd ⇒ at least one real coefficient (a₀); N even ⇒ at least two (a₀ and a_{N/2}). This is exactly the statement Recitation 4 Exercise 4 asks you to prove.

6Manipulating coefficients without recomputing

The three identities to memorise

SignalCoefficientsComment
x[n − n₀]aₖ e−j2πkn₀/NA pure phase factor per bin
x[n]·(−1)ⁿaₖ e−jπk = aₖ(−1)ᵏShifts the spectrum by N/2
x*(−n)aₖ*Conjugate symmetry ↔ time reversal
Worked solution · 2023 control Exercise 5 (2.5 marks)

Question. A periodic signal x[n] of period N = 8 has coefficients aₖ = −a_{8−k}. The signal y[n] = ((4 + (−1)ⁿ)/2)·x[n−1] is generated. Find the coefficients cₖ of y[n] in terms of aₖ.

Step 1 — split the multiplier.

(4 + (−1)ⁿ)/2 = 2 + (1/2)(−1)ⁿ

Step 2 — find the spectrum of each part. A constant 2 has spectrum 2δ[k]. The sequence (1/2)(−1)ⁿ = (1/2)e^{jπn} has spectrum (1/2)δ[k − N/2] = (1/2)δ[k−4] for N = 8. Multiplying the two spectra (convolution of spectra) leaves the sum:

y[n] = 2·x[n−1] + (1/2)(−1)ⁿ x[n−1]
= 2·x[n−1] + (1/2)·x̃[n]    where x̃[n] = (−1)ⁿx[n−1]

Step 3 — apply the shift and the modulation rules. x[n−1] has coefficients aₖ e^{−j2πk/8}. Multiplying by (−1)ⁿ shifts that spectrum by N/2 = 4 bins. So:

cₖ = 2 aₖ e−j2πk/8 + (1/2) ak−4 e−j2π(k−4)/8

Step 4 — final form. Since e−j2π(k−4)/8 = −e−j2πk/8, combining the two terms gives

cₖ = e−j2πk/8 · { 2aₖ − (1/2) ak−4 }    (all k, indices taken mod 8)

The given symmetry lets you rewrite the shifted term. The coefficients are periodic in k with period 8, and aₖ = −a₈₋ₖ is the same statement as aₖ = −a₋ₖ; applying it at k − 4 and at k + 4 gives ak−4 = ak+4. An equivalent final answer is

cₖ = e−j2πk/8 · { 2aₖ − (1/2) ak+4 }
What the grader wants. The three ingredients — (1) split the multiplier, (2) shift by one sample ⇒ phase factor, (3) multiply by (−1)ⁿ ⇒ shift by N/2 bins with a sign — each worth roughly one point. The symmetry aₖ = −a_{8−k} is what lets you express everything in terms of the aₖ alone.
Worked solution · make-up exam Exercise 5 (3 marks)

Question. For a periodic signal of period N (even), express x[n] − x[n + N/2] and x[n] + x[n + N/2] in terms of aₖ, and derive x*(−n).

Step 1. x[n + N/2] = Σₖ aₖ ej2πk(n+N/2)/N = Σₖ aₖ ejπk ej2πkn/N = Σₖ aₖ(−1)ᵏ ej2πkn/N.

Step 2 — the difference.

x[n] − x[n+N/2] = Σₖ aₖ(1 − (−1)ᵏ) ej2πkn/N = 2 Σk odd aₖ ej2πkn/N

Only the odd bins survive, doubled.

Step 3 — the sum.

x[n] + x[n+N/2] = 2 Σk even aₖ ej2πkn/N

Only the even bins survive, doubled.

Step 4 — time reversal. x*(−n) = Σₖ aₖ* e−j2πkn/N = Σₖ a₋ₖ* ej2πkn/N. So the coefficients of x*(−n) are aₖ* — and for a real signal this is exactly the conjugate symmetry a₋ₖ = aₖ* restated.

Memory hook. Shifting by N/2 multiplies bin k by (−1)ᵏ: even bins add, odd bins cancel.

7Exam connections

2023 control · Ex 3
N = 5, aₖ = jᵏ for −1 ≤ k ≤ 1 and aₖ = −1 for k = ±2. What is x[0]?
Solution
−1. x[0] = Σₖ aₖ because every exponential is 1 at n = 0. The coefficients in 0…4 order are [1, j, −1, −1, −j] (note a₋₂ = a₃ = −1 and a₋₁ = a₄ = −j). Their sum is 1 + j − 1 − 1 − j = −1.
2024–25 control · Ex 3.2
N = 7, a₀ = 0, a±₁ = 1, a±₂ = 2, a±₃ = 1. What is Σₙ₌₀⁶|x[n]|²?
Solution
84. Parseval: Σₙ₌₀⁶|x[n]|² = N·Σₖ₌₀⁶|aₖ|². Σ|aₖ|² = 0 + 2(1 + 4 + 1) = 12, and 7 × 12 = 84.
2023 control · Ex 1.4
“A real discrete-time periodic signal has real Fourier series coefficients.” True or false?
Solution
False. A real signal gives a₋ₖ = aₖ*, so only a₀ (and a_{N/2} when N is even) must be real. Example: x[n] = cos(2πn/N + π/4) is real but has a₁ = ½e−jπ/4.
Checklist. Be able to: (1) write the synthesis sum with the right index range; (2) pair conjugate terms to get a cosine sum; (3) compute x[0] = Σaₖ without expanding; (4) apply Parseval with the factor N; (5) apply the shift and modulation rules to coefficients.
