Discrete-Time Signals and Systems

1Discrete-time signals

A discrete-time signal is a sequence of numbers indexed by the integers. We write x[n], and the brackets are the reminder that n is an integer, not a continuous time.

δ[n] = 1 for n = 0, 0 otherwise   ·   u[n] = 1 for n ≥ 0, 0 otherwise   ·   u[−n−1] = 1 for n ≤ −1 (the anti-causal unit step)
The off-by-one that loses marks. u[n] is 1 at n = 0, so u[n] − u[n−1] = δ[n]. And u[−n−1] is 1 at n = −1, not at n = 0: that is exactly the “strictly before zero” step you need for every anti-causal inverse Z-transform.

2Periodic, energy and power signals

Periodicity

x[n] is periodic if there is a positive integer N such that x[n+N] = x[n] for every n. The fundamental period N₀ is the smallest such N.

SignalPeriodic?How to see it
x[n] = cos(2πn/N)YesPeriod N exactly (for integer N ≥ 1)
x[n] = cos(ω₀n), ω₀ = 2πp/N with p, N coprimeYesFundamental period N
x[n] = cos(2n)No2 is not a rational multiple of 2π
x[n] = e^{jω₀n}Yes iff ω₀/(2π) is rationalWrite ω₀ = 2πp/q
x[n] = u[n], δ[n]NoNo shift returns them
x[n] = A (constant)YesEvery N works; the fundamental period is 1
Exam shortcut. For a sum of complex exponentials, the period is the smallest N with ω₀N = 2πm for every frequency present. If one of them is irrational relative to 2π, the sum is not periodic. Recitation 1 Exercise 1 is nine sub-questions of exactly this.

Energy and power

Energy E = Σₙ |x[n]|²   ·   Power P = limN→∞ (1/(2N+1)) Σₙ₌₋ᴺᴺ |x[n]|²

A signal is an energy signal if 0 < E < ∞ (then its power is 0). It is a power signal if 0 < P < ∞ (then its energy is infinite). A signal cannot be both, and the only signal that is neither is the zero signal.

SignalTypeValue
x[n] = δ[n]EnergyE = 1
x[n] = aⁿu[n], |a| < 1EnergyE = 1/(1−|a|²)
x[n] = aⁿu[n], |a| > 1PowerP = ∞ (energy also ∞) — neither
x[n] = A cos(ω₀n + φ)PowerP = A²/2
x[n] = u[n]PowerP = 1/2
x[n] = A (constant)PowerP = A²
Watch the constant. A DC signal is periodic (any period) and a power signal with P = A², not A²/2. The factor ½ only appears for a sinusoid, because the cosine and sine split the energy evenly.

Shift direction is the classic slip. x[n − 3] moves the waveform to the right (delays it). x[n + 3] moves it left (advances it). If you draw it the other way, every downstream answer is wrong even though the algebra looks fine.

4Convolution

y[n] = (x * h)[n] = Σₖ₌₋∞^∞ x[k]·h[n−k]

Read it as: flip h about the origin, slide it along x, multiply sample by sample, and add up. The value of the sum at position n is y[n].

The three rules that make convolution fast

  1. Support first. If x[n] ≠ 0 only for n ∈ [n₁, n₂] and h[n] ≠ 0 only for n ∈ [m₁, m₂], then y[n] = 0 outside [n₁+m₁, n₂+m₂]. Draw the two supports, add the endpoints, and you know where to look.
  2. Length grows. Two sequences of lengths L₁ and L₂ convolve to length L₁ + L₂ − 1.
  3. Count the overlapping terms. This is where the archived 2024–25 solution goes wrong. In y[n] = Σₖ x[k]h[n−k], the number of non-zero products is the number of indices where the two supports overlap — and that number changes with n. For two right-sided sequences it is n+1, not ∞. That is why the answer is (n+1)(1/3)ⁿ and not a geometric series.
Convolution explorerslide h[−k] across x and watch the running sum
Worked solution · 2023 control Exercise 4 (5 marks)

Question. Compute and plot y[n] = x[n] * h[n] where x[n] = h[n] = u[n+20] − u[n−21].

Step 1 — write the sequences. u[n+20] is 1 for n ≥ −20; u[n−21] is 1 for n ≥ 21. Their difference is a rectangle of height 1 on −20 ≤ n ≤ 20, i.e. 41 samples. Outside that, x[n] = h[n] = 0.

Step 2 — support. [−20,20] + [−20,20] = [−40,40]. So y[n] = 0 outside [−40, 40], and y has 81 samples.

Step 3 — count the overlap. For −40 ≤ n ≤ 0 the overlap has n + 41 points; for 0 ≤ n ≤ 40 it has 41 − n points. Every product equals 1, so the sum is just the count:

y[n] = { n + 41    −40 ≤ n ≤ 0
         41 − n    0 ≤ n ≤ 40
         0        elsewhere }

Step 4 — plot. A triangle: it starts at 1 at n = −40, rises by 1 each sample to a peak of 41 at n = 0, then falls symmetrically back to 1 at n = 40. The peak value equals the length of the rectangle (41), not 40 and not 42.

Marks. Support (1) · the two cases of the formula (2) · the correct plot with the peak labelled 41 (2).
Worked solution · 2024–25 control Exercise 4 (5 marks) — and the trap

Question. Convolve x[n] = h[n] = (1/3)ⁿu[n].

Step 1. x[k] = (1/3)ᵏ for k ≥ 0, zero otherwise; same for h.

Step 2 — how many terms? Both sequences are right-sided, so in y[n] = Σₖ x[k]h[n−k] the index k must satisfy k ≥ 0 (from x) and n − k ≥ 0 (from h), i.e. 0 ≤ k ≤ n. For n ≥ 0 that is exactly n + 1 terms; for n < 0 it is zero terms, so y[n] = 0.

Step 3 — the sum. Every product is (1/3)ᵏ·(1/3)ⁿ⁻ᵏ = (1/3)ⁿ:

y[n] = (n+1)·(1/3)ⁿ    for n ≥ 0,   and y[n] = 0 for n < 0

Step 4 — the plot. It starts at 1 at n = 0, rises to a maximum of 2/3 at n = 1, then decays. It is not a geometric decay — the envelope is the straight line (n+1).

The trap. The archived handwritten solution writes y[n] = (1/3)ⁿ·Σₖ₌₀^∞(1/3)^{2k} = (9/8)(1/3)ⁿ. The mistake is replacing a finite sum whose length is n+1 with an infinite geometric series. A convolution sum is always finite (two supports can only overlap in finitely many places). If your answer behaves like a pure exponential, you have silently assumed infinite overlap.

Use them in the exam. Recitation 2 Exercise 2 asks you to convolve six pairs and then explicitly says “use your knowledge of linearity and time invariance to minimize the work in parts (d)–(f)”. Those three parts are all shifts, scalings and sums of one base convolution — do not recompute them from scratch.

5The four system properties

A discrete-time system maps an input x[n] to an output y[n]. Four questions decide almost every mark in the control:

PropertyThe test you must write downShortcuts
Linear T{a·x₁ + b·x₂} = a·T{x₁} + b·T{x₂} for all scalars a, b Any term containing two inputs (x[n]x[n], x[n]²) is not linear. Any absolute value, square or sign function is not linear.
Time-invariant T{x[n−n₀]} = y[n−n₀] for every n₀ Shifting the input shifts the output by the same amount. A factor that depends on n ((n+1), cos(πn/10), n) breaks time-invariance.
Causal y[n] depends only on x[k] for k ≤ n For LTI: h[n] = 0 for n < 0. A term x[n+1] or x[2n] (for n > 0) makes it non-causal.
Stable every bounded input gives a bounded output For LTI: Σₙ |h[n]| < ∞. A bounded input is one with |x[n]| ≤ M.
Memoryless y[n] depends only on x[n] Ask: can I change x[n−1] without changing y[n]? If yes, it has memory.
Causal and stable are independent. h[n] = u[n] is causal and unstable (Σ|h[n]| = ∞). h[n] = (1/2)ⁿu[−n−1] is stable (Σ|h[n]| = 1) and non-causal. Both appear in the past controls.
System property checkernumeric tests, the same way you must argue them on paper
Worked solution · 2023 control Exercise 2.1 (5.5 marks)

Question. Is y[n] = (n+1)x[n−1] linear, time-invariant, causal, stable?

Linearity. T{a x₁ + b x₂} = (n+1)(a x₁[n−1] + b x₂[n−1]) = a(n+1)x₁[n−1] + b(n+1)x₂[n−1] = a·y₁[n] + b·y₂[n]. Linear.

Time-invariance. T{x[n−n₀]} = (n+1)x[n−n₀−1] but y[n−n₀] = (n−n₀+1)x[n−n₀−1]. They differ by n₀. Not time-invariant.

Causality. y[n] uses x[n−1], a past sample. Causal.

Stability. Take the bounded input x[n] = e^{jn} (|x| = 1). Then |y[n]| = |n+1|·|e^{j(n−1)}| = |n+1|, which is unbounded. Not stable.

Pattern to imitate. Four short paragraphs, each with the test named, the substitution written, and the verdict in bold. About 1 mark per property.
Worked solution · 2024–25 control Exercise 2.2 (5 marks)

Question. For h[n] = (1/2)ⁿu[n] + 2ⁿu[−n−1], is the system causal and/or stable?

Causality. h[n] is non-zero for n ≤ −1 (the term 2ⁿu[−n−1]), so the system is not causal.

Stability. Σₙ |h[n]| = Σₙ₌₀^∞ (1/2)ⁿ + Σₙ₌₋∞^(-1) 2ⁿ = 2 + 1 = 3 < ∞. Stable.

Note the sums. Σₙ₌₀^∞ (1/2)ⁿ = 2 and Σₙ₌₋∞^(-1) 2ⁿ = 1 (the anti-causal geometric series is finite because 2ⁿ shrinks as n → −∞). Both are finite ⇒ stable.

6Impulse response and the LTI idea

Feed the system the impulse δ[n] and record what comes out. That record is the impulse response h[n] — and for an LTI system it is everything you need:

y[n] = x[n] * h[n]     (LTI ⇒ output = convolution of input with impulse response)
QuestionAnswer in terms of h[n]
Is it causal?h[n] = 0 for all n < 0
Is it stable?Σₙ |h[n]| < ∞
Is it memoryless?h[n] = K·δ[n] only
What is the output to a unit step?y[n] = u[n] * h[n] — the running sum of h
Is it LTI?h[n] fully characterises an LTI system; a general system needs more
Why this matters for the control. The 2023 True/False block is built on these two lines: “An LTI system with a finite-duration impulse response is always stable” — True, because a finite sequence is automatically absolutely summable. “The impulse response of a causal LTI system satisfies Σ|h[n]|² < ∞” — False, because causal says nothing about the size of h (take h[n] = u[n]).

7Exam connections

2023 control · Ex 4
x[n] = h[n] = u[n+20] − u[n−21]. The convolution y[n] has a peak of 41 at n = 0 and is zero outside [−40, 40]. True or false?
Solution
True. Each sequence has 41 ones (−20 ≤ n ≤ 20). Their convolution is a triangle of base 81 and height 41, peaking at n = 0. The support is [−20,20] + [−20,20] = [−40,40]. The height equals the length of one rectangle, because at n = 0 all 41 ones overlap with all 41 ones.
Recitation 1 · Ex 3
Which of these is not a linear system? (a) y[n] = x[n]x[n]   (b) y[n] = |x[n]|   (c) y[n] = 3x[n] + x[n−2]   (d) y[n] = x[n−1]
Solution
Both (a) and (b). T{a x₁ + b x₂} = (a x₁ + b x₂)² ≠ a x₁² + b x₂², and |a x₁ + b x₂| ≠ a|x₁| + b|x₂|. Any product of two inputs, any square, any absolute value or sign function destroys linearity. (c) and (d) are linear.
Make-up exam · Ex 1
Is y[n] = x[n] − x[n−2] stable?
Solution
Yes. Write it as a convolution: y[n] = x[n] * (δ[n] − δ[n−2]), so h[n] = δ[n] − δ[n−2] and Σ|h[n]| = 1 + 1 = 2 < ∞. Bounded input ⇒ bounded output. (Causality and stability are independent, as always: this system is also causal and non-memoryless.)
