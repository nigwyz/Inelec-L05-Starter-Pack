1System properties

2023 control · Ex 2.1 (5.5 marks)
For y[n] = (n+1)x[n−1], which combination is correct?
Full solution

Linearity. T{ax₁+bx₂} = (n+1)(ax₁[n−1]+bx₂[n−1]) = a(n+1)x₁[n−1] + b(n+1)x₂[n−1] = a y₁[n] + b y₂[n] ⇒ linear.

Time-invariance. T{x[n−n₀]} = (n+1)x[n−n₀−1], but y[n−n₀] = (n−n₀+1)x[n−n₀−1]. They differ by n₀ ⇒ not time-invariant.

Causality. Only x[n−1] is used ⇒ causal.

Stability. x[n] = e^{jn} is bounded, but |y[n]| = |n+1| → ∞ ⇒ not stable.

2023 control · Ex 2.2 (part of 5.5 marks)
h[n] = (1/2)ⁿu[n] + 2ⁿu[−n−1]. Which is true?
Full solution

Causality. The term 2ⁿu[−n−1] is non-zero for n ≤ −1, so h[n] ≠ 0 for some n < 0 ⇒ not causal.

Stability. Σ|h[n]| = Σₙ₌₀^∞(1/2)ⁿ + Σₙ₌₋∞^(-1)2ⁿ = 2 + 1 = 3 < ∞ ⇒ stable.

The anti-causal sum is finite because 2ⁿ shrinks as n → −∞.

2024–25 control · Ex 2.1 (5 marks)
For y[n] = cos(π/10)·x[n−2], which combination is correct?
Full solution

Linear: the gain is a constant, so superposition holds.

Time-invariant: T{x[n−n₀]} = cos(π/10)x[n−n₀−2] = y[n−n₀] ✓.

Causal: x[n−2] is a past sample ✓.

Stable: |y[n]| ≤ |cos(π/10)|·M ≤ M ✓.

Memoryless? No — it uses x[n−2]. The question did not ask, but this is the trap: the system is LTI and stable yet it has memory.

Make-up exam · Ex 1 (3.5 marks)
y[n] = x[n] − x[n−2]. Which set of answers is correct?
Full solution

Linear: superposition holds on both terms.

Not memoryless: y[n] needs x[n−2].

Time-invariant: both shifts are fixed.

Stable: h[n] = δ[n] − δ[n−2], Σ|h[n]| = 2 < ∞.

2True / False — 2023 Exercise 1

#StatementAnswerOne-line reason
1An LTI system with a real finite-duration impulse response is always stable. TRUE A finite sequence is absolutely summable: Σ|h[n]| is a finite sum of finite numbers.
2The impulse response of a causal LTI system satisfies Σ|h[n]|² < ∞. FALSE Causality only says h[n] = 0 for n < 0. h[n] = u[n] is causal and has infinite energy.
3The output of an LTI system is always determined by the convolution sum. TRUE y[n] = x[n]*h[n] — that is the definition of an LTI system.
4A real discrete-time periodic signal has real Fourier series coefficients. FALSE A real signal only forces a₋ₖ = aₖ*. Example: cos(2πn/N + π/4) has a₁ = ½e^{−jπ/4}.
Negative marking. With 4 statements and −1 per wrong answer, a blind guess has expected value 0 but a systematic 50/50 guess loses marks. Only answer the ones you can justify.

3Fourier series — the 15-mark block

2023 control · Ex 3.1
N = 5, aₖ = jᵏ for −1 ≤ k ≤ 1, aₖ = −1 for k = ±2. Which is x[n]?
Full solution

Move to 0…4: a₀=1, a₁=j, a₂=−1, a₃=a₋₂=−1, a₄=a₋₁=−j.

x[0] = 1 + j − 1 − 1 − j = −1.

Pairing conjugates with θ = 2πn/5:

x[n] = 1 + j(e^{jθ} − e^{−jθ}) − (e^{j2θ} + e^{−j2θ}) = 1 − 2sinθ − 2cos2θ.

Check: x[0] = 1 − 0 − 2 = −1 ✓. Values over one period: −1, 0.7159, −0.7936, 1.5575, 4.5201.

2023 control · Ex 3.2
Same signal. Σₙ₌₀⁴ |x[n]|² = ?
Full solution

Σ|aₖ|² = |1|²+|j|²+|−1|²+|−1|²+|−j|² = 5. Parseval: Σ|x[n]|² = N·5 = 25.

2024–25 control · Ex 3.1
N = 7, a₀ = 0, a±₁ = 1, a±₂ = 2, a±₃ = 1. Which is x[n]?
Full solution

Real symmetric coefficients ⇒ pair k with −k:

x[n] = a₀ + Σₖ₌₁³ aₖ(e^{j2πkn/7} + e^{−j2πkn/7}) = 2a₁cos(2πn/7) + 2a₂cos(4πn/7) + 2a₃cos(6πn/7)

= 2cos(2πn/7) + 4cos(4πn/7) + 2cos(6πn/7).

Check: x[0] = 8 = Σaₖ = 2(1+2+1) ✓.

2024–25 control · Ex 3.2
Same signal. Σₙ₌₀⁶ |x[n]|² = ?
Full solution

Σ|aₖ|² = 0 + 2(1+4+1) = 12. Σ|x[n]|² = 7 × 12 = 84.

Make-up exam · Ex 2
Periodic x[n] with x[0]=1, x[±1]=0, x[±2]=0.5, x[±3]=1. What is a₀ (period N = 6)?
Full solution

a₀ = (1/N)Σₙ x[n] = (1 + 0 + 0.5 + 1 + 0.5 + 0)/6 = 3/6 = 0.5.

The other coefficients: a₁ = −1/12, a₂ = 0.25, a₃ = 1/6, a₄ = 0.25, a₅ = −1/12 (all real, because x[n] is real and even).

4Convolution

2023 control · Ex 4 (5 marks)
x[n] = h[n] = u[n+20] − u[n−21]. Which describes y = x*h?
Full solution

Each sequence is 1 on −20 ≤ n ≤ 20 (41 samples).

Support: [−20,20] + [−20,20] = [−40,40].

Overlap count: n+41 for −40 ≤ n ≤ 0, and 41−n for 0 ≤ n ≤ 40.

So y is a triangle starting at 1, rising to 41 at n = 0, back to 1 at n = 40.

Plot: 81 samples, symmetric, peak equal to the length of one rectangle.

2024–25 control · Ex 4 (5 marks)
x[n] = h[n] = (1/3)ⁿu[n]. What is y[n]?
Full solution

For n ≥ 0, the index k runs over 0 ≤ k ≤ n — that is n+1 terms, each equal to (1/3)ⁿ.

y[n] = (n+1)(1/3)ⁿ for n ≥ 0, and 0 for n < 0.

Values: 1, 2/3, 1/3, 4/27, … The maximum is 2/3 at n = 1.

Why (b) is wrong: it replaces a finite sum of length n+1 by an infinite geometric series. See the warning on the exam-map page.

Make-up exam · Ex 3 (4 marks)
x[n]=u[n], h[n]=(1/5)ⁿu[n]. What is y[n] for n ≥ 0?
Full solution — both methods

Time domain. y[n] = Σₖ₌₀ⁿ (1/5)ⁿ⁻ᵏ = Σₘ₌₀ⁿ (1/5)ᵐ = (1 − (1/5)ⁿ⁺¹)/(1 − 1/5) = (5/4)(1 − (1/5)ⁿ⁺¹).

Z-transform. X(z) = 1/(1−z⁻¹), H(z) = 1/(1−⅕z⁻¹), both with |z| > 1.

Y(z) = 1/[(1−z⁻¹)(1−⅕z⁻¹)] = A/(1−z⁻¹) + B/(1−⅕z⁻¹) with A = 5/4, B = −5/4.

So y[n] = (5/4)u[n] − (5/4)(1/5)ⁿu[n] — the same result. It settles at 5/4, the DC gain.

5Coefficient manipulation

2023 control · Ex 5 (2.5 marks)
N = 8, aₖ = −a₈₋ₖ, and y[n] = ((4+(−1)ⁿ)/2)x[n−1]. Which is the correct structure of cₖ?
Full solution

(4+(−1)ⁿ)/2 = 2 + ½(−1)ⁿ: a constant plus a modulation.

Shift: x[n−1] multiplies bin k by e^{−j2πk/8}.

Modulation by (−1)ⁿ = e^{jπn} shifts the spectrum by N/2 = 4 bins.

So cₖ = 2aₖe^{−j2πk/8} + ½aₖ₋₄e^{−j2π(k−4)/8}. Since e^{−j2π(k−4)/8} = −e^{−j2πk/8},

cₖ = e^{−j2πk/8}{2aₖ − ½aₖ₋₄}, all indices mod 8.

Make-up exam · Ex 5 (3 marks)
N even. x[n] − x[n+N/2] equals which sum?
Full solution

x[n+N/2] = Σₖ aₖ e^{jπk}e^{j2πkn/N} = Σₖ aₖ(−1)ᵏe^{j2πkn/N}.

Subtracting: the factor is 1−(−1)ᵏ, which is 2 for odd k and 0 for even k ⇒ 2Σ_{k odd}.

Adding gives 2Σ_{k even} aₖe^{j2πkn/N}.

And x*(−n) has coefficients aₖ*.

6Make-up exam — the Z-transform questions

Make-up exam · Ex 4 (4 marks)
H(z) = (2z⁻¹−1)/[(1−½z⁻¹)(1−⅓z⁻¹)]. For the causal system, h[n] = ?
Full solution

Partial fractions: H(z) = A/(1−½z⁻¹) + B/(1−⅓z⁻¹).

A(1−⅓z⁻¹) + B(1−½z⁻¹) = 2z⁻¹ − 1 gives A+B = −1 and A/3 + B/2 = −2.

Solving: A = 9, B = −10. Check: 9 − 3z⁻¹ − 10 + 5z⁻¹ = −1 + 2z⁻¹ ✓.

Causal (ROC |z| > ½): h[n] = 9(½)ⁿu[n] − 10(⅓)ⁿu[n].

Anti-causal (ROC |z| < ⅓): every term becomes left-sided: h[n] = −9(½)ⁿu[−n−1] + 10(⅓)ⁿu[−n−1].

Notice the ROC decides which of the two answers is the right one. The algebra is identical; only the strip of convergence differs.

The ROC is the answer. The same H(z) gives a decaying right-sided h[n] for the causal choice and a growing left-sided one for the anti-causal choice. Always write the ROC next to H(z) before inverting.

7Recitation drills 1–3

Recitation 1 · Ex 1
Is x[n] = cos(2n) periodic?
Solution

We need 2(n+N) = 2n + 2πm, i.e. N = πm for some integer m. Since π is irrational, no integer N works ⇒ not periodic. A discrete-time sinusoid is periodic only when its frequency is a rational multiple of 2π.

Recitation 1 · Ex 2
What type of signal is x[n] = u[n], and what is its value?
Solution

E = Σₙ₌₀^∞ 1 = ∞, so it is not an energy signal. Its average power over [0, M] is (M+1)/(2M+1) → ½, so it is a power signal with P = ½.

Recitation 2 · Ex 2
x[n] = δ[n−4], h[n] = 2ⁿu[n−1]. What is y[n]?
Solution

Convolution with a shifted impulse is a shift: δ[n−4] * h[n] = h[n−4] = 2^{n−4}u[n−5].

The support check: h starts at n = 1, shifted by 4 ⇒ starts at n = 5 ✓.

Recitation 3 · the central idea
You observe T{δ[n]} = h[n] and T{δ[n−1]} = h[n−1]. What does that prove?
Solution

Nothing yet. Time-invariance is the statement T{x[n−n₀]} = y[n−n₀] for every input and every shift. Testing it on two impulses is consistent with time-invariance but cannot establish it.

What observations can do is disprove a property. If you observed T{δ[n−1]} = h[n+1] instead, that single pair would be enough to conclude the system is not time-invariant.

That asymmetry is the whole point of Recitation 3: a counter-example is a proof; a consistent example is not.

The recitation 3 rule to remember. If the system is known to be time-invariant, then T{x[n−n₀]} = y[n−n₀] lets you predict outputs for shifted inputs. If it is known to be linear, T{ax₁+bx₂} = ay₁+by₂ lets you predict outputs for combinations. If neither is known, you can only check consistency — never prove.
