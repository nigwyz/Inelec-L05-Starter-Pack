Chapter 2

Discrete-Time LTI Systems

Once a system is LTI, one sequence describes it completely. This chapter is about that sequence: how to get it from a difference equation, how to read causality and stability off it, and how interconnections combine.

1The LTI idea

An LTI system satisfies linearity and time-invariance. The consequence is enormous: the output is the convolution of the input with the impulse response, and nothing else about the system matters.

y[n] = x[n] * h[n] = Σₖ x[k]h[n−k]
PropertyIn terms of h[n]Consequence
Causalh[n] = 0 for n < 0The sum only needs past samples
StableΣₙ |h[n]| < ∞Bounded in ⇒ bounded out
Memorylessh[n] = Kδ[n]Only a gain
Time-reversibleh[−n] must be causal and stableNeeded for deconvolution
Linearity is what makes the sum work. The response to x[n] = Σₖ x[k]δ[n−k] is Σₖ x[k]h[n−k] by linearity, and time-invariance is what lets you use the same h for every shifted impulse. Drop either assumption and the convolution sum is wrong.

2Difference equations and recursion

Σk=0M ak y[n−k] = Σk=0N bk x[n−k]   ⇒   y[n] = −(1/a₀) Σk=1M ak y[n−k] + (1/a₀) Σk=0N bk x[n−k]

Set the input to the impulse x[n] = δ[n] and the output becomes the impulse response h[n]. The recurrence is then

h[n] = −(1/a₀) Σk=1M ak h[n−k]  +  (b₀/a₀) δ[n]    (n ≥ 0)

with h[n] = 0 for n < 0. The recursion is mechanical: at each step you only need earlier values.

Difference-equation solverimpulse response, step response, and the recursion table
Worked example · first-order system

System: y[n] = ½ y[n−1] + x[n].

Impulse response. Put x[n] = δ[n]:

h[n] = ½ h[n−1] + δ[n],   h[−1] = 0

h[0] = ½·0 + 1 = 1; h[1] = ½·1 + 0 = ½; h[2] = ¼; in general h[n] = (½)ⁿu[n].

Properties. h[n] = 0 for n < 0 ⇒ causal. Σₙ |h[n]| = 1/(1−½) = 2 < ∞ ⇒ stable.

Step response. With x[n] = u[n], y[n] = u[n]*h[n] = Σₖ₌₀ⁿ (½)ᵏ = 2(1 − (½)ⁿ⁺¹), which starts at 1 and settles at 2.

The pattern. A stable first-order system with a pole inside the unit circle has an impulse response that decays and a step response that settles to the DC gain 1/(1−a).

3Interconnections: cascade and parallel

InterconnectionImpulse responseIn the z-domain
Cascade (h₁ then h₂)h = h₁ * h₂H(z) = H₁(z)H₂(z)
Parallel (sum of outputs)h = h₁ + h₂H(z) = H₁(z) + H₂(z)
Difference (subtract outputs)h = h₁ − h₂H(z) = H₁(z) − H₂(z)
Feedback (h₁ forward, h₂ backward, gain g)h = h₁ / (1 + g h₁h₂)H = H₁/(1 + g H₁H₂)
Why the cascade is a convolution. The impulse enters the first system, which produces h₁[n]; that signal is the input to the second system, which produces h₂ * h₁. So the overall impulse response is h₁ * h₂ — the order does not matter.

4Deconvolution

Knowing h = h₁ * h₂ and h₁, you can solve for h₂. Two ways:

  1. Recursion. Write the convolution as an equation and solve it step by step. For h₁[n] = δ[n] − δ[n−2]:
    h[n] = h₂[n] − h₂[n−2] ⇒ h₂[n] = h[n] + h₂[n−2], with h₂[n] = 0 for n < 0.
  2. Polynomial division in z. H₂(z) = H(z)/H₁(z). Since H₁(z) = 1 − z⁻², the division is a running sum with lag 2 — the same recursion in disguise.
Deconvolution needs care. The recursion h₂[n] = h[n] + h₂[n−2] has to be run for every residue class mod 2, and you must continue far enough to see the pattern settle. Stopping early is how you lose the last marks of the question.

5Realisations and the system function

A difference equation is one description of a system; a block diagram is another. The professor's slides build the same system in three ways, and the exam may ask you to draw any of them:

RealisationHow it is drawnWhat it shows
Direct form IOne delay chain per side of the equationEverything at once, but many delays
Direct form II (canonical)One shared delay chainFewest delays — M of them for order M
CascadeOne first-order section per poleThe poles sit at the section roots
What matters for the exam. The system function H(z) = Y(z)/X(z) is the polynomial ratio you get from the difference equation, and its roots are the poles. Chapter 5 adds the one thing that decides causality and stability: the region of convergence.

6Exam connections

Chapter 1 ↔ Chapter 2
An LTI system has impulse response h[n] = δ[n] + δ[n−3]. Is it causal? Is it stable?
Solution
Causal and stable. Causality: h[n] = 0 for all n < 0 ✓. Stability: a finite-length impulse response is automatically absolutely summable, Σ|h[n]| = 1 + 1 = 2 ✓. This is the generalisation of 2023 True/False 1: any LTI system with a finite-duration impulse response is stable.
Recitation 2 · Ex 4
The impulse response is h[n] = 2ⁿu[−n−1]. Is the system causal? Is it stable?
Solution
Not causal, but stable. h[n] ≠ 0 for n ≤ −1 ⇒ non-causal. Σₙ₌₋∞^(-1) 2ⁿ = 1 ⇒ the sum is finite ⇒ stable. Magnitude is what matters for stability, not the direction. A sequence can grow as n → −∞ and still be stable if it shrinks fast enough — here 2ⁿ shrinks.
Recitation 2 · Ex 3
Cascade of three causal LTI systems: h₁[n] = δ[n] − δ[n−2] and the overall response has h[0]=1, h[1]=5, h[2]=10, h[3]=11, h[4]=8, h[5]=4, h[6]=1. What is h₂[2] if h = h₁ * h₂?
Solution
11. h[n] = h₂[n] − h₂[n−2] ⇒ h₂[n] = h[n] + h₂[n−2]. So h₂[0] = 1, h₂[1] = 5, h₂[2] = 10 + h₂[0] = 11. Continuing: h₂[3] = 11 + 5 = 16, h₂[4] = 8 + 11 = 19, h₂[5] = 4 + 16 = 20, h₂[6] = 1 + 19 = 20, and it settles at 20.
Checklist. Be able to: (1) compute an impulse response from a difference equation by recursion; (2) state causality and stability from h[n] with the reason; (3) write the overall impulse response of a cascade and of a parallel pair; (4) run a deconvolution recursion to the point where the pattern settles.
