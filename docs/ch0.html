1The big picture in one paragraph

A computer is a stack of agreements. At the bottom, a transistor is a switch. Switches arranged in the right pattern become a logic gate. Gates plus feedback become a register, which can hold a bit pattern. Registers plus an ALU plus a control path become a CPU. The CPU reads instructions from memory, and those instructions move data between registers and memory. Memory, buses, and I/O turn the CPU into a system. An interrupt lets the outside world break the sequence without corrupting the program.

That is the whole course. Chapter 1 builds the bottom, Chapter 2 connects the blocks, and Chapter 3 makes the CPU execute. The controls then test whether you can trace a specific instruction through that stack.

The one sentence to remember

Bits live in registers, registers are moved by instructions, instructions live in memory, and the CPU repeats fetch–execute until it meets a halt.

3The ten control rules

These are the recurring rules distilled from the two study PDFs and the five available controls. They are not a substitute for understanding—they are the checklist you run after you understand the machine.

Rule 1

Register size follows the bus it serves

PC and MAR hold an address → same width as the address bus. MBR holds a memory word → same width as the data bus or memory location. GPR/AC hold data → the CPU’s data width. IR must hold the fetched instruction → the instruction width, or the opcode width if the CPU fetches operands separately.

State the convention: “8 bits for a 1-byte opcode, 16 bits for a 2-byte opcode.”

Rule 2

X, [X], and [[X]] are three different things

X is the value or the address itself. [X] is the content of memory location X. [[X]] (or #X) is a double pointer: read [X], treat that as an address, then read again.

Every memory trace starts by writing the address under every byte.

Rule 3

Little-endian: little end first

The least-significant byte goes to the lowest address. A 16-bit value read at 2348H takes its low byte from [2348H] and its high byte from [2349H].

15H at 2348H, F5H at 2349H
→ 16-bit value = F515H
Rule 4

Two’s complement in two moves

Look at the leading hex digit. 0–7 means positive: convert normally. 8–F means negative: subtract each digit from F, add 1, convert, put a minus sign. Or invert all bits and add 1.

F5H → (FFH − F5H) + 1 = 0BH = 11 → −11
Rule 5

Instruction size = opcode bytes + operand bytes

Read the format table. A 1-byte opcode with an 8-bit operand is 2 bytes; with a 16-bit operand it is 3 bytes. A 2-byte prefix opcode with a 16-bit operand is 4 bytes. Encode multi-byte operands low byte first.

LD IX,3000H → DD 21 00 30 → 4 bytes
Rule 6

Five addressing modes

Immediate (n), register (R), direct ((nn) or [X]), register indirect ((HL), (As)), memory indirect ([[X]]). The brackets tell you where the address lives.

Rule 7

Fetch and execute have different rules for MAR/MBR

At the end of a fetch of an instruction of size S at Addr: PC = Addr + S, MAR = Addr + S − 1, MBR = [Addr + S − 1], IR = the instruction. During execute, MAR/MBR change only if the instruction actually accesses memory.

If the execute reads/writes a 16-bit value, the final MAR is the higher address and MBR is the byte read there.

Rule 8

States and T-states

IAC, IF, IOD happen for every instruction. Add OAC and OF for memory operands, DO for an ALU operation, OS for a memory write. Then sum the T-states: opcode fetch 4, operand fetch 3 per byte, memory read/write 3 per byte.

Rule 9

The stack grows down

PUSH: SP decreases first, then the value is written. POP: the value is read first, then SP increases. A 16-bit pair is stored low byte first; POP reads the low byte from [SP] and the high byte from [SP+1].

PUSH BC: SP−2; [SP]=C; [SP+1]=B
Rule 10

Interrupts finish the instruction first

The CPU completes the current instruction, then pushes PC, then loads the ISR address. In Z80 mode 2: pointer = I×256 + device_data; the ISR address is the 16-bit value stored at that pointer.

I=23H, data=4CH → pointer 234CH
PC = [234DH][234CH]
Use the rules as questions, not as memorized answers. The two study PDFs disagree in a few places (especially IR width and the “fetch” boundary). The safe exam habit is: state the convention you are using, show the transfer, and keep the arithmetic consistent.

Across the five papers, the highest-yield skills are:

  • tracing an instruction through PC, MAR, MBR, IR (5/5 papers);
  • decoding instruction size and hex code from a supplied table (5/5);
  • reading little-endian memory and two’s-complement values (4–5/5);
  • PUSH/POP and the stack pointer (4/5);
  • carry, overflow, sign, and zero flags (4/5);
  • machine cycles and T-states (3/5);
  • CMOS and tri-state logic (2/5);
  • interrupts and ISR addressing (1/5, but a full 20-point paper in 2024–25).
How to read the point values. The newest paper gives 13.5 points to Z80 execution and only 6.5 to basic concepts. That does not mean ignore the concepts—6.5 points is the difference between 13.5/20 and 20/20. It means the CPU trace is where most of the time should go.

5The six-step solver

Every control question can be attacked with the same six steps. Write them on the back of your mind, not on the exam sheet.

1 · Identify the machine

Word size, address-bus width, data-bus width, endianness, instruction size, memory organization. These determine every register width and every byte order.

2 · Identify the instruction

Find it in the supplied table. Write its format, its size, and the width of each operand. Then encode it, low byte first.

3 · Fetch

MAR ← PC, MBR ← [MAR], IR ← instruction, PC ← PC + S. Record the final MAR, MBR, IR, PC.

4 · Execute

Decode the opcode, compute the effective address, read the operands, do the operation, write the result. Update MAR/MBR only if memory was touched.

5 · Side effects

Did it change flags? SP? A register pair? Did it push or pop? Did it jump? Did an interrupt arrive? These are the marks students lose.

6 · Check units

Hex digits, bytes vs. bits, T-states vs. machine cycles, decimal vs. hex. A correct method with the wrong unit still loses the mark.

6Diagnostic — five questions before you start

Answer without notes. If you miss more than two, start with Chapter 1; if you miss two, skim Chapter 1 and begin Chapter 2; if you miss none, go straight to Chapter 2 and use Chapter 1 only for reference.

1 · Chapter 1
What is 1110 0010₂ as an 8-bit two’s-complement number?
Show answer
MSB is 1 → negative. Invert: 0001 1101, add 1: 0001 1110 = 30. Answer −30.
2 · Chapter 2
A 16-bit address bus with byte-addressable memory can address how many bytes?
Show answer
2^16 = 65 536 locations × 1 byte = 64 KB.
3 · Chapter 2
[2348H] = 15H and [2349H] = F5H on a little-endian CPU. What is the 16-bit word at 2348H?
Show answer
Low byte at the low address: low = 15H, high = F5H → F515H.
4 · Chapter 3
LD IX,3000H at 2000H. After the full fetch, what is PC?
Show answer
The instruction is DD 21 00 30 = 4 bytes. PC = 2000H + 4 = 2004H.
5 · Chapter 3
Z80 IM2, I = 23H, device data = 4CH. What address holds the ISR start address?
Show answer
Pointer = I×256 + data = 2300H + 4CH = 234CH. The two bytes there (little-endian) form the ISR address.
