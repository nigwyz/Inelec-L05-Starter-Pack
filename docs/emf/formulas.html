Constants and units

Constant
Vacuum permittivity
ε₀ = 1/(36π) × 10⁻⁹ ≈ 8.854 × 10⁻¹² F/m
Use 10⁻⁹/(36π) when the problem gives charges in nC: the 36π cancels the 4π.
Constant
Vacuum permeability
μ₀ = 4π × 10⁻⁷ H/m
Then μ₀/(4π) = 10⁻⁷ exactly; this is why Biot–Savart arithmetic stays clean.
Constant
Speed of light
c = 1/√(μ₀ε₀) ≈ 3 × 10⁸ m/s
Constant
Free-space impedance
η₀ = √(μ₀/ε₀) = 120π ≈ 377 Ω
Constant
Elementary charge
e = 1.602 × 10⁻¹⁹ C
Units
What the answer should be
E: V/m · D: C/m² · B: T = Wb/m² · H: A/m · V: V · Q: C · F: N

Chapter 1 — Vectors & coordinate systems

Vector algebra

Definition
Vector and unit vector
A = A âA,   |âA| = 1
Product
Dot product
A·B = AB cosθ = AxBx + AyBy + AzBz
Scalar. Projection of B on A: B cosθ = A·B/A.
Product
Cross product
|A×B| = AB sinθ
A×B = | x̂ ŷ ẑ ; Ax Ay Az ; Bx By Bz |
Vector. Direction by the right-hand rule; magnitude = parallelogram area.
Product
Triple products
A·(B×C) = B·(C×A) = C·(A×B)
A×(B×C) = B(A·C) − C(A·B)
Scalar triple = signed volume of the parallelepiped.

Coordinates

System
Cartesian (x, y, z)
−∞ < x,y,z < +∞
r = x x̂ + y ŷ + z ẑ
Use for boxes, planes, and general points with no symmetry.
System
Cylindrical (ρ, φ, z)
0 ≤ ρ < ∞,   0 ≤ φ < 2π
ρ = √(x² + y²),   φ = tan⁻¹(y/x),   z = z
A = Aρ ρ̂ + Aφ φ̂ + Az ẑ
Use for wires, cylinders, and coaxial structures.
System
Spherical (r, θ, φ)
0 ≤ r < ∞,   0 ≤ θ ≤ π,   0 ≤ φ < 2π
r = √(x² + y² + z²),   θ = cos⁻¹(z/r)
A = Ar r̂ + Aθ θ̂ + Aφ φ̂
Use for point charges, spheres, and cones. θ is measured from +z, not from the xy-plane.

Unit-vector transformations

The matrices below convert components at the same point. Evaluate the angles at that point first.

Matrix
Cylindrical → Cartesian
Ax = cosφ Aρ − sinφ Aφ
Ay = sinφ Aρ + cosφ Aφ
Az = Az
Matrix
Cartesian → Cylindrical
Aρ = cosφ Ax + sinφ Ay
Aφ = −sinφ Ax + cosφ Ay
Az = Az
Matrix
Spherical → Cartesian
Ax = sinθ cosφ Ar + cosθ cosφ Aθ − sinφ Aφ
Ay = sinθ sinφ Ar + cosθ sinφ Aθ + cosφ Aφ
Az = cosθ Ar − sinθ Aθ
Matrix
Cartesian → Spherical
Ar = sinθ cosφ Ax + sinθ sinφ Ay + cosθ Az
Aθ = cosθ cosφ Ax + cosθ sinφ Ay − sinθ Az
Aφ = −sinφ Ax + cosφ Ay
Matrix
Cylindrical ↔ Spherical
Aρ = sinθ Ar + cosθ Aθ
Aφ = Aφ
Az = cosθ Ar − sinθ Aθ
Ar = sinθ Aρ + cosθ Az
Aθ = cosθ Aρ − sinθ Az

Differential elements

dldx x̂ + dy ŷ + dz ẑdρ ρ̂ + ρdφ φ̂ + dz ẑdr r̂ + rdθ θ̂ + r sinθ dφ φ̂

The metric-factor test. If a length is a coordinate step, multiply by the coefficient: ρdφ and r sinθ dφ. If it is a surface, multiply by the Jacobian: ρ or r² sinθ. Most lost marks are here.

Chapter 2 — Vector calculus

Integrals and operators

Integral
Line integral
∫C f dl,   ∫C F·dl,   ∫C F×dl
F·dl is work/circulation; it is a scalar. On a closed path it is ∮.
Integral
Surface integral
Φ = ∫S F·dS = ∫S F·n̂ dS
Only the normal component contributes. On a closed surface, n̂ points outward.
Integral
Volume integral
Q = ∫V ρv dv
Operator
Gradient — Cartesian
∇f = (∂f/∂x)x̂ + (∂f/∂y)ŷ + (∂f/∂z)ẑ
Operator
Gradient — cylindrical
∇f = (∂f/∂ρ)ρ̂ + (1/ρ)(∂f/∂φ)φ̂ + (∂f/∂z)ẑ
Operator
Gradient — spherical
∇f = (∂f/∂r)r̂ + (1/r)(∂f/∂θ)θ̂ + (1/(r sinθ))(∂f/∂φ)φ̂
Operator
Divergence — Cartesian
∇·A = ∂Ax/∂x + ∂Ay/∂y + ∂Az/∂z
Operator
Divergence — cylindrical
∇·A = (1/ρ)∂(ρAρ)/∂ρ + (1/ρ)∂Aφ/∂φ + ∂Az/∂z
Operator
Divergence — spherical
∇·A = (1/r²)∂(r²Ar)/∂r + (1/(r sinθ))∂(sinθ Aθ)/∂θ + (1/(r sinθ))∂Aφ/∂φ
Operator
Curl — Cartesian
| x̂ ŷ ẑ ; ∂/∂x ∂/∂y ∂/∂z ; Ax Ay Az |
Operator
Curl — cylindrical
[(1/ρ)∂Az/∂φ − ∂Aφ/∂z]ρ̂
+ [∂Aρ/∂z − ∂Az/∂ρ]φ̂
+ (1/ρ)[∂(ρAφ)/∂ρ − ∂Aρ/∂φ]ẑ
Operator
Curl — spherical
(1/(r sinθ))[∂(Aφ sinθ)/∂θ − ∂Aθ/∂φ]r̂
+ (1/r)[(1/sinθ)∂Ar/∂φ − ∂(rAφ)/∂r]θ̂
+ (1/r)[∂(rAθ)/∂r − ∂Ar/∂θ]φ̂
Operator
Laplacian ∇²f = ∇·∇f
Cartesian: ∂²f/∂x² + ∂²f/∂y² + ∂²f/∂z²
Cylindrical: (1/ρ)∂(ρ∂f/∂ρ)/∂ρ + (1/ρ²)∂²f/∂φ² + ∂²f/∂z²
Spherical: (1/r²)∂(r²∂f/∂r)/∂r + (1/(r²sinθ))∂(sinθ∂f/∂θ)/∂θ + (1/(r²sin²θ))∂²f/∂φ²
Theorem
Divergence theorem
∮S A·dS = ∫V (∇·A) dv
Closed surface ↔ enclosed volume. The normal is outward.
Theorem
Stokes's theorem
∮C A·dl = ∫S (∇×A)·dS
Closed loop ↔ any open surface bounded by it. Orientation by the right-hand rule.
Identity
Two identities worth memorizing
∇·(∇×A) = 0
∇×(∇f) = 0

Chapter 3 — Electrostatics

Law
Coulomb's law
F12 = (1/(4πε₀)) (Q₁Q₂/R²) â12
F = (1/(4πε₀)) Σ qi(r − ri)/|r − ri|³ · q
Field
Electric field
E = F/qt = (1/(4πε₀)) (q/R²) âR
E = (1/(4πε₀)) Σ qi(r − ri)/|r − ri|³
Points away from +q, toward −q. Units V/m.
Sources
Charge elements
dq = ρl dl = ρs dS = ρv dv
ρl: C/m, ρs: C/m², ρv: C/m³.
Field
E of a distribution
E = (1/(4πε₀)) ∫ (ρl dl′)(r − r′)/|r − r′|³
E = (1/(4πε₀)) ∫ (ρs dS′)(r − r′)/|r − r′|³
E = (1/(4πε₀)) ∫ (ρv dv′)(r − r′)/|r − r′|³
Field
Electric flux density
D = εE = ε₀εrE
D is independent of the medium; E is not.
Law
Gauss's law
∮S D·dS = Qenc = ∫V ρv dv
∇·D = ρv
Potential
Electric scalar potential
VAB = VA − VB = −∫BA E·dl
E = −∇V
V = (1/(4πε₀)) q/R   (point charge, V(∞)=0)
Potential
V of a distribution
V = (1/(4πε₀)) ∫ ρl dl′/|r − r′|
V = (1/(4πε₀)) ∫ ρs dS′/|r − r′|
V = (1/(4πε₀)) ∫ ρv dv′/|r − r′|
Result
Ring of charge, on axis
Ez = Q z/(4πε₀(b² + z²)3/2)
b is the ring radius; E=0 at the center and →Q/(4πε₀z²) far away.
Result
Annular disk, on axis
Ez = (ρs/(2ε₀))[z/√(a²+z²) − z/√(b²+z²)]
a = inner radius, b = outer radius. For a full disk set a=0.
Result
Line charge fields
Infinite line: E = ρl/(2πε₀ρ) ρ̂
Semi-infinite, at the end: E = ρl/(4πε₀z) ẑ
Energy
Electrostatic energy density
we = ½ D·E = ½ εE²
J/m³. Useful when the field is known everywhere.

Chapter 4 — Magnetostatics

Law
Biot–Savart law
dB = (μ₀/4π)(I dl×âR)/R²
B = (μ₀/4π) ∫ I dl′×R/R³
dl points with the current; R points from the element to P.
Result
Infinite straight wire
B = μ₀I/(2πρ) φ̂
H = I/(2πρ) φ̂
Concentric circles; right-hand rule with the thumb along I.
Result
Finite wire
B = (μ₀I/(4πρ))[b/√(ρ²+b²) − a/√(ρ²+a²)] φ̂
a and b are the signed endpoints on the z-axis; let a→−∞, b→∞ for the infinite case.
Law
Ampère's circuital law
∮C H·dl = Ienc
∮C B·dl = μ₀Ienc
B = μH = μ₀μrH
Result
Solenoid and toroid
Solenoid: B = μ₀ n I   (n = N/L)
Toroid: B = μ₀NI/(2πρ)
Force
Magnetic force
F = qv×B
F = I L×B
F = q(E + v×B)   (Lorentz force)
F is perpendicular to both v and B; it does no work on a free charge.
Force
Two parallel wires
F/L = μ₀I₁I₂/(2πd)
Same direction → attract; opposite → repel.
Law
Gauss's law for B
∮S B·dS = 0
∇·B = 0
No magnetic monopoles; B lines close on themselves.
Energy
Magnetic energy density
wm = ½ B·H = ½ μH²

Displacement current density
Jd = ∂D/∂t
Id = ∫ Jd·dS = ε dΦE/dt

Continuity equation
∇·J + ∂ρv/∂t = 0
∮S J·dS = −dQ/dt
Material
Constitutive relations
D = εE,   B = μH,   J = σE
Faraday
Induced emf
emf = ∮E·dl = −dΦB/dt
Lenz: the induced current opposes the change in flux.

Chapter 6 — Uniform plane waves

Free space
Wave number
k₀ = ω√(μ₀ε₀) = ω/c = 2π/λ
Free space
Wavelength and period
λ = 2π/k₀ = c/f
T = 1/f = 2π/ω
Free space
Intrinsic impedance
η₀ = Ex/Hy = √(μ₀/ε₀) = 120π ≈ 377 Ω
Free space
Traveling wave
Ex = Ex0 cos(ωt − k₀z)
Hy = (Ex0/η₀) cos(ωt − k₀z)
E = η₀ H × ẑ,   H = (1/η₀) ẑ × E
Medium
General medium
k = ω√(με) = β − jα
η = √(μ/ε),   vp = 1/√(με),   λ = 2π/β
n = √(εrμr)   (refractive index)
Loss
Loss tangent
tan δ = σ/(ωε)
Small tanδ → good dielectric. Large tanδ → good conductor.
Conductor
Good conductor
α = β = √(πfμσ)
δ = 1/α = 1/√(πfμσ)
η = (1+j)√(ωμ/(2σ)) = (1+j)/(σδ)
Field falls by e−1 in one skin depth (37%); 5δ → <1%.
Dielectric
Low-loss dielectric
α ≈ (σ/2)√(μ/ε),   β ≈ ω√(με)
η ≈ √(μ/ε)
Units
Attenuation conversion
1 Np = 8.686 dB
αdB/m = 8.686 αNp/m
Polarization
How to identify it
Δφ = 0 or π → linear
Δφ = ±π/2 and equal amplitudes → circular
otherwise → elliptical
