Chapter 2 · Vector calculus

Line integrals, gradient, divergence, curl — and the two theorems

This is the chapter that unlocks the control's six-point flux question. You will add a field along a curve, across a surface and through a volume; compress those sums into ∇f, ∇·A and ∇×A; then undo the compression with the divergence theorem and Stokes. Every operator is written in Cartesian, cylindrical and spherical coordinates, because the control's closed surface is spherical.

Where this chapter pays. Control 2024–25, Exercise 1 is a closed-surface flux in spherical coordinates followed by a divergence-theorem check. The worked example in §2.5 reproduces the full 27π result, face by face. Exercise 2 then uses the volume integral Q = ∫ρv dv, so the same differential-element discipline carries straight over.

Notation, fixed once. Cylindrical coordinates are (ρ, φ, z); spherical coordinates are (r, θ, φ). In both, φ is the azimuth and θ is the polar angle measured from +z. The volume charge density is ρv (the subscript keeps it distinct from the cylindrical radius ρ). A bold letter is a vector; a hat is a unit vector.

2.1Line, surface and volume integrals

All three integrals use the same recipe: cut the object into small pieces, multiply the field by the size of the piece, add, then shrink the pieces. What changes is the object — a curve, a sheet, or a solid — and therefore what “size” means.

Line integral: work along a curve

A curve C carries a differential displacement dl. Its direction is the direction of travel; its length is the small arc length dl. Reversing the traversal reverses dl.

∫C f dl   (scalar)   ·   ∫C f dl   (vector)
∫C F · dl   (work)   ·   ∫C F × dl   (vector)

The dot-product version is the one the exam uses. It is the work done by F along the path:

W = ∫C F · dl = ∫t0t1 F(r(t)) · r′(t) dt

Only the component of F along the path contributes. If F is perpendicular to dl everywhere on a leg, that leg contributes zero — no matter how large the field is.

Surface integral: flux through a sheet

A surface element has area dS and a unit normal n̂. The vector area is dS = n̂ dS. The normal is a choice, but for a closed surface the convention is fixed: it points outward.

Φ = ∫S F · dS = ∫S F · n̂ dS

Φ is the flux: the amount of F crossing the sheet. The tangential part of F slides along the sheet and contributes nothing. For a closed surface, positive flux means more field leaves the volume than enters it.

The other two surface integrals are less common but appear in the lecture's definitions: ∫S f dS is a vector, and ∫S F × dS is a vector.

Volume integral: total charge

∫V f dv   (scalar)   ·   ∫V F dv   (vector)
Q = ∫V ρv dv

The volume integral adds a density over a solid. If the density is charge per unit volume, the result is total charge. If it is mass per unit volume, the result is total mass. The integrand supplies the physics; the integral supplies the bookkeeping.

Line integral on two pathsdrag t; switch the route

Worked Example 2.1 — two paths, one answer

Take F = y x̂ + x ŷ. Evaluate ∫F·dl from the origin to (1, 1, 0) along two routes:

  • Path 1: (0, 0, 0) → (1, 0, 0) → (1, 1, 0).
  • Path 2: the straight segment (0, 0, 0) → (1, 1, 0).

Path 1, first leg: (0, 0, 0) → (1, 0, 0)

On this leg y = 0, z = 0, so dy = dz = 0 and dl = dx x̂. The field on the leg is F = 0 x̂ + x ŷ. Therefore

F · dl = (0 x̂ + x ŷ) · (dx x̂) = 0   ⟹   ∫01 0 dx = 0

The field points in ŷ; the path points in x̂. They are perpendicular, so this leg does no work.

Path 1, second leg: (1, 0, 0) → (1, 1, 0)

Now x = 1, z = 0, so dx = dz = 0 and dl = dy ŷ. The field is F = y x̂ + 1 ŷ, so

F · dl = (y x̂ + ŷ) · (dy ŷ) = dy
∫01 dy = 1

Path 1 total: 0 + 1 = 1.

Path 2: the straight line

Parameterize the segment by t from 0 to 1: x = t, y = t, z = 0. Then dx = dy = dt and dl = (x̂ + ŷ) dt. The field is F = t x̂ + t ŷ, so

F · dl = (t x̂ + t ŷ) · (x̂ + ŷ) dt = 2t dt
∫01 2t dt = [t2]01 = 1

Both routes give 1. The field is path-independent — and the potential below proves it for every path, not just these two.

The shortcut. F = y x̂ + x ŷ is the gradient of f = xy: ∂f/∂x = y, ∂f/∂y = x. Therefore the integral from A to B is f(B) − f(A) = xy|(1,1) − xy|(0,0) = 1. In the exam, show the path integral — but use the potential to check it.

Path independence, stated precisely

For a field F on a simply connected region, these three statements are equivalent:

  1. ∫AB F·dl has the same value for every path from A to B.
  2. ∮C F·dl = 0 for every closed loop C.
  3. F = ∇f for some scalar potential f (equivalently, ∇×F = 0).

In electrostatics the potential is written with a minus sign, E = −∇V, because the electric force pushes a positive charge from high potential to low potential. The mathematics is the same; the sign is a physics convention.

Direction and limits. ∫AB = −∫BA. In Example 2.1, the first leg contributes zero because y = 0 there, not because the integral of x is zero. Write the parameterization of each leg separately and keep its limits. A sign error on one leg is the most common way to lose the whole line-integral mark.

Two quick checks that prepare the control

Surface flux. For D = 3r2 r̂ through a sphere of radius b:

∮ D·dS = ∫02π∫0π (3b2)(b2 sinθ) dθ dφ = 3b4(2)(2π) = 12πb4

At b = 2 this is 192π C. The radial field is constant on the sphere, so the integral collapses to (field) × (area).

Volume charge. For ρv = ρ0 r/a inside a sphere of radius a:

Q = ∫02π∫0π∫0a (ρ0r/a) r2 sinθ dr dθ dφ = (ρ0/a)(2π)(2)(a4/4) = πρ0a3

The same setup, with different θ limits, is Control 2024–25 Exercise 2. The integration is mechanical once dv is written correctly.

Exam skill unlocked. Given a field and a curve, you can parameterize each leg, compute F·dl, and integrate. Given a closed surface, you can write dS on each face with the correct outward normal.

2.2Gradient and the directional derivative

A scalar field f(x, y, z) assigns a number to every point — temperature, pressure, potential. The gradient turns that scalar field into a vector field that answers two questions: which way is uphill? and how steep is it?

From a differential to a direction

The chain rule gives the change in f over a small displacement dl:

df = (∂f/∂x)dx + (∂f/∂y)dy + (∂f/∂z)dz
= [(∂f/∂x) x̂ + (∂f/∂y) ŷ + (∂f/∂z) ẑ] · (dx x̂ + dy ŷ + dz ẑ) = ∇f · dl

Divide by the step length dl:

df/dl = ∇f · (dl/dl) = ∇f · û = |∇f| cosθ

where û is the unit vector in the direction of the step and θ is the angle between ∇f and û. The derivative is largest when cosθ = 1, that is, when you walk parallel to ∇f. Its maximum value is |∇f|. It is zero when you walk along a level curve, perpendicular to ∇f.

Gradient. ∇f points in the direction of steepest ascent of f. Its magnitude |∇f| is the slope in that direction, in units of f per metre. It is perpendicular to the level surface f = constant.

Reading a contour map

A contour map draws the level curves f = c for several constants c. Three rules let you read the gradient directly from the picture:

  • ∇f is perpendicular to the contour. If you move along a contour, f does not change, so df = ∇f·dl = 0. A nonzero gradient can only be perpendicular to that displacement.
  • Contours close together mean a steep slope. The same change Δf happens over a shorter distance, so |∇f| is larger.
  • The arrow points from lower to higher values. If the labels increase to your right, the gradient points right, across the contours.

At a local maximum or minimum, the gradient vanishes. At a saddle point it also vanishes, but the contours cross instead of closing. The origin of f = x2y − y3 is exactly this case.

Gradient on a contour mapdrag the probe; switch hill / saddle

The Cartesian formula is the definition. The curvilinear formulas come from comparing df with ∇f·dl and using the metric factors in dl.

The del operator is the same object with the field left blank:

∇ = x̂ ∂/∂x + ŷ ∂/∂y + ẑ ∂/∂z

By itself ∇ has no value. It becomes a gradient when it acts on a scalar, a divergence when it dots a vector, and a curl when it crosses a vector.

Worked Example 2.3 — three systems, one recipe

The lecture's Example 2.3 asks for the gradient of three functions. The point is not the algebra; it is that the same partial derivatives appear, multiplied by the metric factors of the coordinate system.

(a) f1 = ax2y + by3z

∂f1/∂x = 2axy,   ∂f1/∂y = ax2 + 3by2z,   ∂f1/∂z = by3
∇f1 = 2axy x̂ + (ax2 + 3by2z) ŷ + by3 ẑ

(b) f2 = aρ2 sinφ + bρz cos 2φ

∂f2/∂ρ = 2aρ sinφ + bz cos 2φ
(1/ρ) ∂f2/∂φ = (1/ρ)(aρ2 cosφ − 2bρz sin 2φ) = aρ cosφ − 2bz sin 2φ
∂f2/∂z = bρ cos 2φ
∇f2 = (2aρ sinφ + bz cos 2φ) ρ̂ + (aρ cosφ − 2bz sin 2φ) φ̂ + bρ cos 2φ ẑ

Watch the factor 1/ρ in the φ̂ component. Without it, the units are wrong: the φ derivative is with respect to an angle, not a length.

(c) f3 = a/r + br sinθ cosφ

∂f3/∂r = −a/r2 + b sinθ cosφ
(1/r) ∂f3/∂θ = b cosθ cosφ
(1/(r sinθ)) ∂f3/∂φ = −b sinφ
∇f3 = (−a/r2 + b sinθ cosφ) r̂ + b cosθ cosφ θ̂ − b sinφ φ̂

Worked example — f = x2y − y3

∂f/∂x = 2xy,   ∂f/∂y = x2 − 3y2
∇f = 2xy x̂ + (x2 − 3y2) ŷ

At P(1, 2):

∇f(1, 2) = 4 x̂ + (1 − 12) ŷ = 4 x̂ − 11 ŷ
|∇f| = √(42 + 112) = √137 ≈ 11.70

The steepest ascent at P is in the direction (4, −11)/√137. The directional derivative toward Q(2, 4) uses the unit vector (1, 2)/√5:

Dûf = ∇f·û = (4)(1/√5) + (−11)(2/√5) = −18/√5 ≈ −8.05

The value is negative, so f decreases in that direction. The level curve through P has f = 12·2 − 23 = −6. A tangent to it must be perpendicular to ∇f; (11, 4) works because 4·11 + (−11)·4 = 0. The gradient is normal to the contour, not along it.

The only critical point is (0, 0), where both partials vanish. It is a saddle: along y = 0 the function is 0, while along x = 0 it is −y3, which changes sign. The contours cross there, and the gradient arrow has zero length.

The identity ∇r = r̂

In spherical coordinates r is the first coordinate, so immediately

∇r = (∂r/∂r) r̂ + (1/r)(∂r/∂θ) θ̂ + (1/(r sinθ))(∂r/∂φ) φ̂ = r̂

In cylindrical coordinates, the same point is at distance r = √(ρ2 + z2) from the origin:

∂r/∂ρ = ρ/√(ρ2 + z2),   ∂r/∂φ = 0,   ∂r/∂z = z/√(ρ2 + z2)
∇r = (ρ ρ̂ + z ẑ)/√(ρ2 + z2) = r̂

This identity is used constantly in electrostatics. Two consequences worth memorising:

∇(1/r) = −r̂/r2
∇(1/|r − r′|) = −(r − r′)/|r − r′|3
Gradient mistakes that cost marks.
  • Missing metric factors. The φ̂ component in cylindrical needs 1/ρ; the θ̂ and φ̂ components in spherical need 1/r and 1/(r sinθ).
  • Mixing the angles. In this course, cylindrical is (ρ, φ, z) and spherical is (r, θ, φ). Do not write a cylindrical formula with θ as the azimuth.
  • Treating ∇f as tangent to the contour. It is normal to the contour. The tangent is perpendicular to ∇f.
  • Forgetting the product rule. In f1, the y derivative of by3z is 3by2z, not 3by2.

2.3Flux and divergence

Flux is a global count: how much field crosses a surface. Divergence is the local version: how much flux is created per unit volume at a point.

Flux through a closed surface

Φ = ∮S A · dS

For a closed surface, dS points outward. Three cases:

  • No source inside: every field line that enters also leaves, so Φ = 0.
  • Source inside: more lines leave than enter, so Φ > 0.
  • Sink inside: more lines enter than leave, so Φ < 0.

The sign is a statement about the net flow. A region can have plenty of field passing through and still have zero net flux.

Definition of divergence

∇·A = limΔv→0 (1/Δv) ∮S A · dS

Read it as flux per unit volume. It is a scalar. Positive divergence means a source; negative means a sink; zero means incompressible (solenoidal).

For a small Cartesian box, the flux through the two faces normal to x is [Ax(x+Δx) − Ax(x)]ΔyΔz. Dividing by Δv = ΔxΔyΔz and taking the limit gives ∂Ax/∂x. Add the other two pairs:

∇·A = ∂Ax/∂x + ∂Ay/∂y + ∂Az/∂z
Divergence: source or sink?move the probe; cross the zero line

The divergence in all three systems

System∇·AIntuition
Cartesian∂Ax/∂x + ∂Ay/∂y + ∂Az/∂zThree independent face pairs, each of area ΔyΔz, etc.
Cylindrical(1/ρ) ∂(ρAρ)/∂ρ + (1/ρ) ∂Aφ/∂φ + ∂Az/∂zThe curved faces at ρ and ρ+Δρ have different areas; that difference produces the 1/ρ.
Spherical(1/r2) ∂(r2Ar)/∂r + (1/(r sinθ)) ∂(sinθ Aθ)/∂θ + (1/(r sinθ)) ∂Aφ/∂φThe r2 is the sphere area; the sinθ is the shrinking of the θ faces near the poles.

In cylindrical coordinates the radial term is often misremembered as (1/ρ)∂Aρ/∂ρ. It is not: the product ρAρ is differentiated as a product. In spherical coordinates the radial term has the same structure with r2Ar.

Preview: ∇·D = ρv

In electrostatics the flux density D (units C/m2) has divergence equal to the volume charge density (units C/m3):

∇·D = ρv

This is Gauss's law in differential form. Field lines of D begin on positive charge and end on negative charge. Chapter 3 integrates this equation over volumes to get the integral form of Gauss's law.

Worked example — a divergence-free field

Take D = 2(x + y) x̂ + (3x − 2y) ŷ. Then

∂Dx/∂x = 2,   ∂Dy/∂y = −2,   ∂Dz/∂z = 0
∇·D = 2 − 2 + 0 = 0

The field is divergence-free, but it is not zero. At (1, 1), D = 4 x̂ + ŷ and the field is very much present. The two terms cancel: the x-component grows with x at rate 2, while the y-component shrinks with y at rate −2.

A nonzero twin: D2 = 2(x + y) x̂ + (3x + y) ŷ gives ∇·D2 = 2 + 1 = 3 at every point. A field can be divergence-free without being uniform, and it can have constant divergence without being radial.

Worked example — the control's field, differentiated

The 2024–25 control gives D = 3r2 r̂ + (12φ/π) φ̂ C/m2. Apply the spherical formula term by term:

(1/r2) ∂(r2·3r2)/∂r = (1/r2)(12r3) = 12r
(1/(r sinθ)) ∂(12φ/π)/∂φ = 12/(πr sinθ)
∇·D = 12r + 12/(πr sinθ)

The θ term is zero because Dθ = 0. At the equator (θ = π/2): at r = 1, ∇·D = 12 + 12/π ≈ 15.82; at r = 1.5, ≈ 20.55; at r = 2, 24 + 6/π ≈ 25.91. These values are the integrand of the volume check in §5.

Near the poles, sinθ → 0 and the second term blows up. That is not a contradiction: the volume element r2 sinθ supplies a compensating factor, so the volume integral stays finite. This cancellation is exactly what the next section uses.

Divergence mistakes that cost marks.
  • Adding unit vectors. Divergence is a scalar. There is no ρ̂ in the answer.
  • Differentiating Aρ instead of ρAρ. The product rule is part of the formula.
  • Using the wrong angular factor in spherical. The θ term is (1/(r sinθ))∂(sinθAθ)/∂θ, not (1/r)∂Aθ/∂θ.
  • Concluding “zero divergence” means “zero field.” It means no net source. The field can still circulate.

2.4Circulation and curl

Divergence measures net outflow. Curl measures rotation: how much a field circulates around a point.

Circulation

C = ∮C A · dl

Circulation is a scalar. It depends on the direction of travel around the loop: reverse the loop and C changes sign.

Definition of curl

Place a tiny planar patch of area ΔS at a point, with unit normal n̂. The circulation per unit area in the limit is the component of the curl along n̂:

(∇×A) · n̂ = limΔS→0 (1/ΔS) ∮C A · dl

The direction of ∇×A is the normal for which this circulation is greatest. The sign follows the right-hand rule: curl the fingers of your right hand in the direction of the loop; your thumb points along n̂.

Paddle-wheel picture. Imagine a tiny paddle wheel in a fluid. The wheel spins fastest when its axle is parallel to ∇×A. Positive curl means counter-clockwise rotation when you look along the axle; negative means clockwise. A radial field A = x x̂ + y ŷ has no rotation, even though the arrows spread outward.
Curl and the paddle wheeldrag the wheel; switch the field

Why the z-component has that form

Take a small rectangle in the xy-plane with corners (x, y), (x+Δx, y), (x+Δx, y+Δy), (x, y+Δy), traversed counter-clockwise. The four edge integrals are

C ≈ Ax(x,y)Δx + Ay(x+Δx,y)Δy − Ax(x,y+Δy)Δx − Ay(x,y)Δy
= [Ay(x+Δx,y) − Ay(x,y)]Δy − [Ax(x,y+Δy) − Ax(x,y)]Δx

Divide by ΔSz = ΔxΔy and take the limit:

(∇×A)z = ∂Ay/∂x − ∂Ax/∂y

The other two components come from rectangles in the yz- and zx-planes.

The curl in all three systems

Cartesian. The determinant is a bookkeeping device for the three partial-derivative combinations:

∇×A = x̂ŷẑ∂/∂x∂/∂y∂/∂zAxAyAz
= (∂Az/∂y − ∂Ay/∂z) x̂ + (∂Ax/∂z − ∂Az/∂x) ŷ + (∂Ay/∂x − ∂Ax/∂y) ẑ

The ŷ term carries a minus sign relative to the naive pattern. That sign is the most common source of a wrong curl.

Cylindrical. The determinant's second column is ρφ̂ and its third row entry is ρAφ. Those factors produce the 1/ρ in front and the 1/ρ inside the ρ̂ term:

∇×A = (1/ρ) ρ̂ρφ̂ẑ∂/∂ρ∂/∂φ∂/∂zAρρAφAz
= [(1/ρ)∂Az/∂φ − ∂Aφ/∂z] ρ̂ + [∂Aρ/∂z − ∂Az/∂ρ] φ̂ + (1/ρ)[∂(ρAφ)/∂ρ − ∂Aρ/∂φ] ẑ

If a printed formula omits the ρ in the first term or the 1/ρ in front, trust the determinant and the metric factors, not the print.

Spherical. The determinant's second column is rθ̂, the third is r sinθ φ̂, and the prefactor is 1/(r2 sinθ):

∇×A = (1/(r2 sinθ)) r̂rθ̂r sinθ φ̂∂/∂r∂/∂θ∂/∂φArrAθr sinθ Aφ
= (1/(r sinθ))[∂(sinθAφ)/∂θ − ∂Aθ/∂φ] r̂
+ (1/r)[(1/sinθ)∂Ar/∂φ − ∂(rAφ)/∂r] θ̂
+ (1/r)[∂(rAθ)/∂r − ∂Ar/∂θ] φ̂

Two identities worth memorising

∇·(∇×A) = 0    (a curl field has no net source)
∇×(∇f) = 0    (a gradient field has no rotation)

For static fields, E = −∇V, so ∇×E = 0. Electrostatic field lines never close on themselves. In a time-varying field, Faraday's law replaces this with ∇×E = −∂B/∂t, so the curl is not zero in general.

Worked example — nonzero curl

Take A = −y x̂ + x ŷ. Then

∂Ay/∂x = 1,   ∂Ax/∂y = −1
∇×A = (1 − (−1)) ẑ = 2 ẑ

The field rotates counter-clockwise about the +z axis. Around the unit square in the xy-plane, the circulation is 2; around a 2 × 1 rectangle it is 4. The curl is constant, so the circulation is curl × area.

Worked example — zero curl

Take A = y x̂ + x ŷ, the field of Example 2.1. Then

∂Ay/∂x = 1,   ∂Ax/∂y = 1,   ∇×A = 0

This field is a gradient: A = ∇(xy). Its circulation around every closed loop is zero, and its line integral is path-independent. Zero curl is the local signature of a conservative field.

A third check: A = x2 ŷ has ∇×A = 2x ẑ. The curl changes sign across the y-axis; the field rotates one way for x > 0 and the other way for x < 0.

Curl mistakes that cost marks.
  • Determinant signs. The ŷ component is ∂Ax/∂z − ∂Az/∂x, not the reverse. Expand the determinant slowly.
  • Dropping metric factors. Cylindrical needs the ρ in ρAφ; spherical needs the r and sinθ factors.
  • “Zero curl means zero field.” False. A = y x̂ + x ŷ has zero curl and is nonzero everywhere.
  • “Zero divergence means zero curl.” Also false. The two operators measure different things.
Exam link. Static E is curl-free, which is why a potential exists. Ampère's law in Chapter 4 uses Stokes to turn ∮B·dl into a surface integral of ∇×B. The determinant skills here are reused there.

2.5The divergence theorem — the 27π example

This is the single most important worked example on the page. Control 2024–25, Exercise 1 is worth 6 points, and it is exactly this calculation.

The theorem

∮S A · dS = ∫V ∇·A dv

S is the closed surface bounding the volume V, and dS points outward. The theorem says: the total flux out of a closed surface equals the sum of all sources inside. It converts a surface integral into a volume integral, or the reverse.

Why it is true, in one paragraph

Cut V into many small cells. For one cell, the flux out of its six faces is ∇·A Δv plus smaller terms. Sum over all cells. Every internal face is shared by two cells, and the two outward normals are opposite, so the internal fluxes cancel in pairs. What survives is the flux through the outer boundary. Taking the limit gives the theorem. The same telescoping argument is behind Stokes.

Orientation: outward, always

On a closed surface, dS = n̂ dS with n̂ pointing out of the volume. On an inner surface — a cavity, or the r = 1 face of a shell — “outward” means toward the cavity, which is the direction of decreasing r. This single convention decides the sign of half the terms.

Divergence theorem: the 27π checkslide the radius probe; compare both sides

The control problem, restated

A vector field is given by

D = 3r2 r̂ + (12φ/π) φ̂   C/m2

and the closed surface is the spherical wedge

1 ≤ r ≤ 2,   0 ≤ θ ≤ π,   π/4 ≤ φ ≤ π/2

You are asked for (1) the flux out of the closed surface and (2) a verification by the divergence theorem.

Although a closed surface has six faces in spherical coordinates, only four have nonzero area here. The faces θ = 0 and θ = π are the two halves of the polar axis: their area element contains sinθ, which vanishes there. The four surviving faces are:

  • S1: the inner sphere r = 1, normal −r̂.
  • S2: the outer sphere r = 2, normal +r̂.
  • S3: the half-plane φ = π/4, normal −φ̂.
  • S4: the half-plane φ = π/2, normal +φ̂.

Face 1: r = 1

The five mistakes that turn 27π into a wrong answer.
  • Normal direction on r = 1. It is −r̂, not +r̂. The inner surface's outward direction points into the cavity.
  • Normal direction on φ = π/4. It is −φ̂, because the volume lies at φ > π/4. The φ = π/2 face is +φ̂.
  • Wrong φ limits. The width is π/2 − π/4 = π/4. Using 0 to π/2 doubles every φ integral and gives 54π, not 27π.
  • Missing r2 sinθ. The volume element is r2 sinθ dr dθ dφ. Drop it and the whole volume integral collapses to 9π instead of 27π. It is also what cancels the 1/(r sinθ) in the divergence.
  • Differentiating 3r2 as 6r. The spherical radial term is (1/r2)∂(r2Dr)/∂r. With Dr = 3r2, the derivative is of 3r4, giving 12r.

2.6Stokes' theorem

The divergence theorem turns a closed-surface flux into a volume integral. Stokes turns a closed-loop circulation into a surface integral of the curl.

The theorem

∮C A · dl = ∫S (∇×A) · dS

S is any orientable surface whose boundary is the closed curve C. The orientation is fixed by the right-hand rule: curl the fingers of your right hand along C; the thumb points along dS. Reverse C and both sides change sign.

Why it is true, in one paragraph

Tile S into small cells. The circulation around one cell is (∇×A)·n̂ ΔS plus smaller terms. Sum over all cells. Every internal edge is traversed twice in opposite directions, so those contributions cancel. What survives is the circulation around the outer boundary. Taking the limit gives Stokes.

Stokes: circulation = curl fluxflip the normal; watch both signs

When to use it

  • The loop is hard, the curl is easy. If ∇×A is constant or simple, integrate it over any convenient surface with the same boundary.
  • The surface is hard, the boundary is easy. Run the theorem backward: compute the loop integral and avoid a messy surface integral.
  • The surface is not flat. Any surface with the same boundary gives the same answer, because the difference of two such surfaces is a closed surface and ∇·(∇×A) = 0.
  • Ampère's law. In magnetostatics, ∮B·dl = μ0Ienc is Stokes applied to ∇×B = μ0J.

Worked example — a 2 × 1 rectangle

Take A = −y x̂ + x ŷ and the rectangle 0 ≤ x ≤ 2, 0 ≤ y ≤ 1 in the plane z = 0. Traverse the boundary counter-clockwise as seen from +z, so n̂ = +ẑ.

Line integral, edge by edge.

C1: (0,0) → (2,0),   y = 0,   dl = dx x̂,   A = x ŷ   ⟹   A·dl = 0
C2: (2,0) → (2,1),   x = 2,   dl = dy ŷ,   A = −y x̂ + 2 ŷ   ⟹   A·dl = 2 dy
C3: (2,1) → (0,1),   y = 1,   dl = dx x̂,   A = −x̂ + x ŷ   ⟹   A·dl = −dx
C4: (0,1) → (0,0),   x = 0,   dl = dy ŷ,   A = −y x̂   ⟹   A·dl = 0

Now integrate each edge with its own limits:

∮ A·dl = 0 + ∫01 2 dy + ∫20 (−1) dx + 0 = 2 + 2 = 4

The third edge contributes +2 because the traversal runs from x = 2 to x = 0, and the integrand is −1: the two minus signs cancel.

Curl flux. From the previous section, ∇×A = 2ẑ, so

∫S (∇×A)·dS = ∫02∫01 (2ẑ)·(ẑ dx dy) = 2(2)(1) = 4

Both sides are 4. If you flip the normal to −ẑ, the boundary traversal reverses and both sides become −4. The magnitude is unchanged; the sign tracks the orientation.

A zero-curl control. For A = y x̂ + x ŷ, ∇×A = 0. The same rectangle gives ∮A·dl = 0. Indeed A = ∇(xy), so the loop integral of a gradient is zero.

Stokes mistakes that cost marks.
  • Inconsistent orientation. Pick the normal first, then traverse the boundary according to the right-hand rule. Do not mix the two.
  • Using a surface whose boundary is not C. The theorem needs the loop to be exactly the boundary of the surface.
  • Forgetting the normal component. Only (∇×A)·n̂ contributes. A curl parallel to the surface integrates to zero.
  • Determinant signs. The same ŷ sign trap as in the curl formula.

2.7Check yourself

Three questions, one per core skill: a line integral, the divergence-theorem flux, and a curl. Answer before opening the solution.

Check 1 · line integral

F = y x̂ + x ŷ. The line integral from (0, 0, 0) to (1, 0, 0) to (1, 1, 0) equals:

Show answer

1. On the first leg y = 0, so F = x ŷ and dl = dx x̂; the dot product is zero. On the second leg x = 1, so F·dl = dy; the integral is 1. Total 0 + 1 = 1. The straight path also gives ∫01 2t dt = 1, and ∇×F = 0, so the field is conservative.

Check 2 · divergence theorem

D = 3r2 r̂ + (12φ/π) φ̂. The outward flux through the closed surface 1 ≤ r ≤ 2, 0 ≤ θ ≤ π, π/4 ≤ φ ≤ π/2 is:

Show answer

27π. The four faces give −3π/2 (r = 1), 24π (r = 2), −9π/2 (φ = π/4) and 9π (φ = π/2). Sum: 27π. The divergence is 12r + 12/(πr sinθ); integrating it over the volume gives 45π/2 + 9π/2 = 27π. The θ = 0 and θ = π faces have zero area.

Check 3 · curl

A = −y x̂ + x ŷ. ∇×A is:

2ẑ. The only nonzero partials are ∂Ay/∂x = 1 and ∂Ax/∂y = −1. Their difference is 2. The field rotates counter-clockwise about +z; a paddle wheel at the origin spins counter-clockwise when viewed from +z.
